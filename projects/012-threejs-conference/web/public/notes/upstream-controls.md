# 原库完整场景的中文控制面板

2026-10-11。固定上游：`8cc20593b2270e2ce832e7b7b44356705daddec4`。原库本机入口为 [5195](http://127.0.0.1:5195/)；原城市、车辆和着色器素材继续保存在忽略的 `vendor/`。

## 用户可以如何体验

ENTER 进入原库城市后，桌面默认展开中文面板。四个开关可在同一个第一人称画布里对照雨滴、水花、湿地镜像、车身水珠与霓虹辉光。点击技术名称会切换观察方法、原理流程、算法边界和固定源码链接。

“全部开启 / 全部关闭 / 只看此项”组合控制四层。街口、车身、倒影三个定位入口保留漫游控制；倒影入口使用蹲下的较低眼高，按 C 可起身。细调参数提供反射强度和可见粒子数量。P、收起按钮和“继续漫游”可隐藏面板；左下角仍可返回中文研究台。

手机尺寸默认收起面板，打开后在限定高度内滚动。桌面用鼠标操作开关后把焦点送回画布，可以直接继续 WASD；键盘操作面板时保留焦点，避免空格和方向键误触漫游。点击面板会退出鼠标锁定并释放输入，拖动画布仍可看景。

## 接入的数据流

`scripts/upstream.mjs` 下载固定版本并复制原创适配模块；`patch-upstream.mjs` 在 `src/main.js` 接入 `connectResearchPanel`，直接传递真实 world、pipeline、相机、控制器和性能配置。控制桥通过各对象已有的接口改变 GPU 资源，不创建替代城市或第二个渲染器。

| 中文控制 | 原库接口 | 实际控制范围 |
| --- | --- | --- |
| 雨滴与水花 | `world.rain.setEnabled` / `ground.setRippleAmount` | 雨丝、水花、路面雨纹；计算在雨关闭时跳过 |
| 湿地反射 | `profile.groundReflection` / `ground.setReflectionEnabled` | 关闭镜像纹理混合和镜像更新；普通高光仍保留 |
| 车身水珠 | `profile.carSurfaceRain` / `setEnabled` / `syncProximity` / 法线 uniform | 车漆和玻璃的水珠材质，独立于降雨，保留距离淡出 |
| 霓虹辉光 | `pipeline.perf.setBloomEnabled` / `setLensflareEnabled` | Bloom 和设备预算允许的镜头光晕；原灯光亮度仍保留 |

反射强度直接设置原 uniform；雨滴数量调用 `setDropCount`，改变可见实例数量，原计算缓冲规模没有随之缩小。

## 两个重要的语义修正

上游每帧把降雨开关传给车身水珠，因此仅调用水珠 setter 会被下一帧覆盖。控制桥包装 `syncProximity`，用水珠开关控制其雨量条件；降雨关闭后仍可研究湿润车身。

固定版本的 `CarDrops` 用于法线的掩码没有按层权重收零。只将 `uIntensity` 设为 0，会清掉湿润粗糙度和玻璃增亮，但仍残留法线扰动。这里用有效水珠强度同步缩放 `uNormalStrength` 与 `uGlassNormalStrength`：关闭后为 0，重新开启恢复原强度，远距离也随之淡出。原水珠 TSL 图案文件未复制到跟踪代码或改写。

辉光关闭时一并关闭相关镜头光晕，避免留下另一种光效让对比不清楚；重新开启尊重原设备预算。原 GTAO、调色、色散、发光材质、灯光、烟雾和飞行器继续保留，“全部关闭”只指这四项技术。

## 验证与限制

10 项自动检查通过：5 项原有 BVH 碰撞检查，5 项新增控制桥检查，覆盖水珠与降雨独立、每帧覆盖、法线清零、距离淡出、反射更新预算、无效强度输入、光晕设备预算、清理恢复与固定接入锚点的幂等性。

原库生产构建通过。浏览器逐项对照显示：关闭降雨后雨丝 / 水花 / 雨纹消失，关闭 Bloom 后招牌边缘更清楚，关闭镜像后倒影消失而原高光保留。车身同机位只开水珠与全部关闭的近景均已记录；实际强度分别为 100% 与 0%，车漆湿润高光随开关改变，原模型贴图纹理仍保留。

桌面 1280 × 800 中，操作雨开关后直接按 W 1.5 秒，相机从 `X -138.6 / Z 34.2` 移到 `X -135.6 / Z 33.5`，面板继续展开；P 收起与再次展开均生效。倒影定位的实际眼高为 `Y -4.55`。键盘将反射强度从 0.08 调到 0.10、雨滴数从 5000 调到 500，输出同步；随后恢复默认参数。390 × 844 中四个开关可操作，文档宽度为 390，面板边界为 X 48–378，无横向溢出。验收后已恢复默认浏览器尺寸。浏览器捕获的 warning / error 日志为空；当前 FPS 仍仅是此窗口瞬时读数。
