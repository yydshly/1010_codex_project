## 两种可实际运行的体验

**原库完整体验，5195**：下载固定版本到忽略的 `vendor/`，保留原城市、Quadra、HDR、湿地纹理、雨丝、水花、TSL 水珠、视频广告、烟雾、飞行器、云、GTAO、Bloom 和玻璃开场。它是本机副本，非作者最新线上版本。首次启动解压约 34.7 MB ZIP 并独立安装依赖；`npm run dev` 同时启动两个服务。

**原创实验，5192**：增加可通行十字路口、16 栋横街建筑、雨夜市集、夜航站台、遮雨棚、灯笼、售货机、电缆、动态广告、18 个蒸汽平面与循环飞行器。街口、市集、站台和避雨亭可快捷定位，也能自行走过去。四层效果与原理说明继续保留。

## 漫游与碰撞

控制器改编自上游 `createWalkControls.js`，加速树复用 `bvh.js` / three-mesh-bvh。可用 WASD、Shift 快走、C 蹲下、拖动看四周、全屏和方向按钮。

BVH 射线探测胸口与两侧的行进方向；碰墙后分别尝试 X / Z 轴移动，因此能沿墙滑行。地面查询保留全部交点，拒绝超过踏步高度的屋顶。原创街区用低成本代理覆盖建筑、车辆、棚柱与边界，粒子的 GPU 高度纹理继续独立工作。

修正上游的重叠地面选择：在可踏步范围内选最高面，避免地面与路缘重叠时被基础地面拉低。窗口失焦、标签隐藏时释放输入，防止持续移动。

## 本机适配与授权

- Vite 改为 8.3.4，localhost HTTP 是可信上下文；不安装部署 CLI、自签名 SSL 插件。
- 原视频内容保留，经 CanvasTexture 以 12 FPS、最长边 512 像素上传。低频上传增加兼容性并限制复制成本；它不等同于原 VideoTexture 上传路径。
- 内置浏览器在鼠标锁定请求处出现 Chromium `UnknownError`。已捕获拒绝并降级到拖动；WASD 不依赖锁定。原库提示同步支持拖动模式。
- 原库采用整页入口并增加中文操作说明和返回链接；页面切换释放场景，避免同时持续渲染两套 GPU 画面。
- 所有高度图通道排除蒸汽与飞行器，避免透明特效成为假屋顶。
- `vendor/` 保持忽略；素材和原水珠图案的独立授权保留，未将其视为全 MIT 或公开发布。见 [THIRD_PARTY](../web/THIRD_PARTY.md)。
