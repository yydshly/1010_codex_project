# 001 导览证据快照

三份文件于 2026-10-12 从研究集的 `001-sakura-crossing/notes/` 复制，记录 2026-10-11 已实际完成的中文导览与 MiniMax 讲解实验。内容保持原样，没有把历史本机地址和未部署阶段文字替换成新的实测结果。

- `tour.md`：路线、声画同步、操作与生产预览范围。
- `tour-voice-generation.json`：脱敏参数、六段声音与字幕时间戳，不包含认证密钥。
- `tour-voice-browser.json`：自然播放到 60 秒的原始浏览器完成状态。

001 的场景、来源与授权以该项目说明为准。005 网页提供固定资料快照并链接既有 001 在线研究街，没有将 001 的全部源代码或应用再次打包到 005。图像快照位于 `../assets/references/`，来源见 `../assets/README.md`。
