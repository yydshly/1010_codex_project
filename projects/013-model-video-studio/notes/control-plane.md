# Google Vids 参考与控制面实现

2026-10-11。参考证据是项目007实际使用Google Vids时留下的 [编辑器截图](../../007-google-vids/assets/actual-production/02-ai-draft-editor.jpg) 与 [实际制作记录](../../007-google-vids/README.md)。Google Vids为闭源SaaS，不存在本次可固定的上游代码tag/commit。只参考交互组织，没有引入Google源码、品牌资源或素材。

## 从原型到编辑器

旧版将标题、正文、配音填入固定模板，时间由音频决定。新控制面把场景拆成独立画布对象，配合素材工具、图层属性和底部时间轴。模型设置是创作能力的一部分，日常编辑直接操作画面。

| Google Vids 中实际见到的工作方式 | 本次实现 | 边界 |
| --- | --- | --- |
| 中央画布选择、摆放内容 | 文字、图片、形状拖动与缩放；属性面板；图层排序 | 没有旋转、关键帧或复杂动画 |
| 底部场景轨道与时间控制 | 拖动排序、缩放时间轴、播放定位、边缘改时长、分割 | 基于场景的单视频轨道，不是完整多轨剪辑器 |
| 素材、文字、配音工具入口 | 本机素材库；文字／形状插入；独立模型与配音 | 没有在线素材搜索、录屏、数字人 |
| 配音与波形 | 实际音频解码为PCM，显示振幅；入点、延迟、音量、静音 | 每场景一条旁白，无背景音乐混音 |
| 视频下载与继续编辑 | 项目持久保存、副本、版本导出、MP4 Range播放 | 本机服务；没有云端协作、评论、权限分享 |

## 数据与渲染

浏览器交互 → 场景 `elements` / `timing` → 带revision的PUT请求 → 服务端白名单检查 → 本机JSON → Canvas与FFmpeg导出。

- `public/composition.js` 在浏览器Canvas和Node Canvas中共用。坐标统一1920×1080，确保文字位置、颜色、图层和尺寸进入成片。
- `lib/editor.mjs` 校验对象类型、素材所属项目、边界、颜色、时间、音量；不接受任意本机文件路径。
- `timing` 保存时长、音频入点、延迟、音量、视频入点和淡入淡出／直接切换。分割时给后一段增加音频与视频入点，避免从头重播。
- 视频原声不参与混音。FFmpeg将背景画布、裁切视频与前景文字分层合成；源视频不足时冻结最后一帧。单场景限制一个矩形视频对象，避免预览与导出能力不一致。
- 字幕是场景口播文字块，可自由编辑位置和样式；未实现逐词时间对齐。改变口播后须重新配音，也可明确选择静音。
- 缺少可见图片素材或有效旁白时导出报错，不用占位图冒充完成。空白纯文字场景可以明确静音导出。
- 每次导出保留新文件。撤销／重做针对当前浏览器编辑历史；旧场景记录在项目中保留供保存后恢复，不删除原素材。

## 验证链路

1. 升级前复制源码、原片和实际项目，57个文件生成SHA-256清单；结束时逐个复验通过，两份原片不变。
2. 浏览器点击“创建项目副本”，在副本中修改标题、X位置110、字号74；保存并重载仍一致。
3. 实际鼠标拖动标题，位置从110/285变为161/336；缩放从720×222变为658×273。撤销恢复排版。
4. 实际拖动场景改变顺序；拖片段边缘将13.2秒变为15.2秒；撤销恢复。
5. 在5秒处分割13.2秒首场景，后一段8.2秒，旁白入点4.8秒、延迟0。保存成功后撤销回六场景。
6. 浏览器上传 `animated-illustration.mp4` 并加入场景6；设置视频入点0.3秒。素材由已有Imagegen插画经FFmpeg缓慢放大形成，不是新的AI动态视频生成。
7. 时间轴显示六段真实PCM波形；实际播放旁白。导出按钮通过API合成67.354秒的1080p H.264/AAC视频，完整解码无错误。
8. 版本弹窗内实际播放，读到1920×1080、67.354秒、currentTime推进至30.379秒且paused为false；浏览器下载版本8，其哈希与服务端一致。最终交付版本11修正限幅器自动增益设置，保持界面设定的音量比例。

最终文件、元数据和实测细节见 [验证JSON](../assets/control-plane/verification.json)。子项目6项测试覆盖共享渲染像素、时间定位、数据校验与原三路模型协议。新增控制面没有再次调用付费模型，继续使用之前真实生成的图片与MiniMax配音。

本轮修复了属性输入事件遗漏、画布指针捕获前重建节点、时间轴容器闭合、视频预览定位、导出自动迁移与音量限幅自动增益问题。验证集中在本机实际831像素宽窗口，宽屏布局与其他操作系统未进行完整设备矩阵测试。
