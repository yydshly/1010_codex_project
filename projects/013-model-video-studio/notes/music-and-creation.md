# 统一创作侧栏与音乐混音

2026-10-11。保留原有画布、素材、旁白和导出，使用项目副本验证新增能力。

## 创作结构

- 中央继续预览和编辑；右侧对象／场景属性在空间不足时通过画布右上角按钮打开。
- 左侧提供故事、角色、口播、音乐、视频／口型，以及素材、文字、图层和模型连接。故事与口播跟随时间轴选中的镜头，音乐按全片时间安排。
- 故事梗概、视觉风格与镜头动作可直接编辑；角色可绑定出场镜头、参考图与音色。配音使用当前讲述者的音色，修改台词或音色需要重新生成。
- 分镜总览和生成任务仍可打开独立工作区；准备请求、提交模型、审核结果、应用素材是不同步骤。准备请求不发起外部调用。

## 音乐的实际能力

从「音乐 → 导入背景音乐」导入 MP3/WAV/M4A，自动加入音乐轨。素材库中的音频也可以选入，旁白不被替换。最多 8 条音乐，可以重叠用于背景音乐或音效。

每条音乐支持全片开始时间、播放长度、素材入点、循环、音量、静音、淡入和淡出。片段超出全片的部分会裁切；关闭循环时，素材结束即停止。循环从所选素材入点重复。时间轴音乐波形来自真实 PCM 解码。

全片混音有总输出、旁白总音量、音乐总音量，以及「口播期间音乐保留」四个控制项。保留比例 45% 表示有口播时音乐降到原音量的 45%，不是减少 45%；100% 不压低。提前 0.2 秒压低，结束后 0.4 秒恢复。按场景延迟、音频入点和可用时长计算口播区间，尚无逐词语音活动检测。

浏览器按共享时间规则同步旁白与音乐；FFmpeg 在场景视频合并后混音，视频流直接复制，音频输出 AAC 48kHz 双声道。导出增加 0.95 峰值限制器。浏览器预览与 AAC 编码不会逐样本相同，高音量叠加可能与导出限制器的听感不同。

## 音乐模型预留协议

模型连接新增 `music`，默认 `provider: disabled`。配置 `studio` 后沿用 `studio-generation/v1` 的 `POST <baseUrl>/tasks` 和 `GET <baseUrl>/tasks/<id>`。原厂接口需要实现自己的适配器。

```json
{
  "protocol": "studio-generation/v1",
  "kind": "music",
  "requestId": "工作台生成的幂等请求编号",
  "model": "你配置的模型名",
  "prompt": "温暖、轻柔的器乐，无人声",
  "duration": 67.3333333333,
  "instrumental": true,
  "outputFormat": "mp3",
  "characters": [],
  "media": []
}
```

排队／生成中返回 `id` 和 `status: queued|running`；完成返回 `status: succeeded` 与 `output.audio_base64`（MP3）。失败返回 `status: failed`。视频与口型仍使用 `output.video_base64`。每路凭据独立，结果最大 50MB，服务重启不会自动重复提交。

音乐说明或全片时长变化会使未应用的音乐请求过期。结果先入音频素材库，审核后才能加入音乐轨；手工关联音频明确标为手工导入。真实音乐模型尚未接入，已验证本地 HTTP 合同。
