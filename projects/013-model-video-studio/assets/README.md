# 实际成品与证据

- `control-plane/final.mp4`：新版控制面编辑后67.354秒成片，包含真实视频素材合成。
- `control-plane/project.json`、`frames/`、素材文件：可再次编辑和导出的新版样例。
- `control-plane/verification.json`：浏览器拖动、缩放、时间轴、播放下载、快照与成片哈希验证。
- `control-plane/editor.jpg`：新版控制面真实截图。
- `control-plane/animated-illustration.mp4`、`video-provenance.json`：用已生成插画做缓慢放大形成的导入视频，并非AI动态视频生成。

- `demo/final.mp4`：人工修改后的65.321秒成片，1080p，中文画面与中文配音。
- `demo/ai-draft.mp4`：62.021秒AI初稿视频。
- `demo/project.json`：可搬移项目，引用本文件夹内图片、声音、海报与视频。
- `demo/ai-draft.json`：Codex原始分镜，没有人工覆盖。
- `demo/scene-*.png`、`demo/scene-*.mp3`：这次实际生成的素材。
- `demo/frames/`：最终导出画面，与视频内容一致。
- `demo/image-provenance.json`：六次内置图像生成的来源与完整提示词。工具未返回底层模型标识。
- `demo/verification.json`：模型调用记录、人工修改清单、文件哈希、ffprobe信息与完整解码结果。
- `workbench-desktop.jpg`、`model-settings.jpg`：真实浏览器截图，未用生成图冒充界面。

依照Imagegen技能，生成图已复制到本子项目；原始工具输出仍保留在Codex默认输出目录。这些插画专为本项目生成，没有使用Google Vids素材。
