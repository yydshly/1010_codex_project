- `web/`：原HTML、CSS、JavaScript、Node服务、模型适配器、渲染器、测试和依赖锁文件。
- `demo/`：62.021秒AI初稿、65.321秒修改后成片、原始AI输出、图片、配音及证据。

## 直接使用

主服务运行时打开 [经典版](http://127.0.0.1:4323/classic)，保留原来的分镜表单、模型设置、配音与导出功能。原项目也保留在顶部项目选择器里。新版演示是在独立副本上制作的。

## 独立恢复

先把快照的 `web` 复制到一个新的子目录，在其中执行 `npm.cmd ci`。将 `projects` 内容复制到该目录下的 `.local/projects`。通过 `STUDIO_PORT` 指定空闲端口后执行 `npm.cmd start`。恢复操作不需要覆盖当前新版。
