## 完整研究摘要 · 2026-10-13

按源库能力、本地扩展与跨项目接入分别说明。

### 能力：程序化生成、三渲二呈现与小世界探索

Sakura Crossing 是以 Three.js 和 Vite 实现的可交互三维场景作品。代码生成日式街区、房屋、招牌、树木、道路和道具，结合布局、灯光与渲染，获得接近二维日式动画背景的观感。

固定上游版本包含球形世界、地形跟随、步行/奔跑、碰撞、售货机与店门、猫和环境动画、电动摩托、列车及铁路道口、星球视角。源码与构建加载已核对；完整上游漫游、骑行和全部交互未逐项实测。

我们的本地扩展包括“一条街＋一家店＋一棵树＋一个交互点”、资料阅读收藏的完整研究街、商业街/林间村落/小广场共用组件实验、可保存的小镇搭建器，以及一分钟中文语音镜头导览。

后续另做了本机 AI 守灯游戏，并接入 012 Rain Kit 的天气、湿地与漫游，形成晴雨樱花街。这些是本地扩展与跨项目接入，不能视为 Sakura 原库自带模型、下雨或 WebGPU 模块。

### 模块：场景、风格、交互、编辑、导览与规则

源库的职责可分为：世界与程序化资产、纹理与招牌、球面/地形/碰撞、玩家与载具控制、地点与环境动画、三渲二材质与后处理。最直接的复用方式是沿用源码组件或提取其中的管线。

本地场景层把建筑、树木、道路、招牌与灯光作为组件，用布局配置和固定种子生成商业街、村落或广场；风格层共用分段光照、冷紫暗部、外壳描边、深度描线、调色和抗锯齿。

产品层用稳定地点 ID 连接开门、阅读、收藏与跳转；搭建器提供增删、拖动/坐标移动、旋转、撤销重做、浏览器存档和 JSON 导入导出；导览用音频时间线同步镜头、字幕与地点动作。

AI 游戏另有本机模型接口、有限动作 Schema、策略校验和确定性执行规则。风格、组件、地点与导览目前是项目内职责，尚未发布成独立通用包；四项 Rain Kit API 属于 012，详见单独的跨项目章节。

### 原理：真实 3D 经由多层风格处理成为动画画面

代码用基础几何与 Canvas 纹理构造世界，MeshToonMaterial 与最近邻渐变纹理把光照压成少量色阶；shader 补丁将暗部偏向冷紫。暖主光、冷补光与反弹光共同组织明暗。

主场景输出颜色和深度 → 线性化深度的二阶差分描线 → 暗部偏紫/高光偏暖的统一调色 → linear→sRGB → FXAA。重点道具叠加反向外壳描边；造型、构图、配色与材质同样影响三渲二观感。

上游先在 XZ 平面组织世界，再映射到半径 160 米的球面；长几何需细分，带转轴的动画物件需保持刚性。可见地形、行走高度和碰撞查询要一致。本地三场景与搭建器沿用平面组件，不等于复现整颗上游星球。

本地编辑通过三维命中选择物件，配置数据驱动重建、历史与序列化；内容按钮与地点命中共用动作。导览按音频 currentTime 同步，AI 只选择允许的策略，移动、碰撞和胜负仍由本地规则执行。

晴雨页另做 WebGPU/TSL 风格适配，并调用 012 的 GPU 高度图遮雨、平面镜像和 BVH 漫游。它证明外部环境能力可与樱花风格组合，不改变本项目原始三渲二方法的来源。

## 为什么研究

它把三件事结合起来：代码生成建筑、道具和招牌；统一材质与配色；用分段光照、深度描线和后处理获得动画感。上游还有可漫游的球形世界、列车、骑行和场景交互，但对本研究集最有价值的是可提取的渲染方法与美术约束。

程序化生成让修改内容更方便，仍需要设计布局和构图。这个项目适合创意首页、作品集、互动展示和小型探索场景，也适合学习如何让新内容保持统一风格。应用价值是本次基于源码的判断，尚未验证商业使用效果。

## 一分钟中文镜头导览

启动同一个 Web 后访问 `http://127.0.0.1:5180/`，点击街景下方“开始一分钟导览”。镜头依次走过街口告示牌（0–20 秒）、研究商店（20–40 秒）、阅读亭（40–60 秒），显示中文字幕，并在商店一站开启卷帘门与灯光。

暂停会冻结镜头、字幕与导览中的店门动画；进度条和章节入口调整后暂停，便于回看。点击“自由探索”，或直接拖动画面、滚轮缩放，会在当前位置接管视角。导览结束后自动回到自由探索；收藏与阅读沿用原有业务入口。打开阅读面板、街景离开视野或页面切到后台会暂停，回来后点击继续。

已加入 MiniMax `speech-2.8-hd` 生成的普通话“温暖少女”讲解。声音、字幕和镜头共用音频播放时间，暂停、自由探索、打开阅读面板或切到后台时一起停下；“讲解声音”按钮可以静音。语音已保存为本地文件，体验时无需账号或调用模型。实现与实测范围见 [镜头导览记录](notes/tour.md)，合成来源见 [语音生成记录](notes/tour-voice-generation.json)。镜头编排由本地重新编写，借鉴 [005 桃源研究快照](references/005-taohuayuan/README.md) 的时间线思路。

打开终端打印的 `http://127.0.0.1:5180/`，保持终端运行。完整安装、构建、操作和子目录验证命令见 [Web 说明](web/README.md)。

上述为本机开发地址；在线研究与体验请访问[已验证的 GitHub Pages 网页](https://yydshly.github.io/1010_codex_project/001-sakura-crossing/research.html)。

根索引已登记 `demo-ready` 与真实在线地址。该状态仅指本次静态研究与体验，模型 API 和 012 独立应用仍需本机服务。

## 关键发现

1. 动画感由分段光照、冷色暗部、描线、统一调色和构图共同产生。
2. 核心渲染模块可以独立于完整世界复用；本地演示不需要球面映射、列车或大量街区。
3. 关闭调色仍需保持正确的 linear → sRGB 转换，比较效果时才能避免误判。
4. 可见地形、碰撞与高度查询必须一致；截图不能证明上游路线真的可达。
5. 第一阶段未做帧率基准；技术实验页已提供帧间隔与定时采样，目标设备的规模预算仍需实机验证。
