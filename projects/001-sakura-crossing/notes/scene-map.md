## 维护

修改 `scene-map-content.json` 后运行：

```powershell
node scripts/render-scene-map.mjs --png --sharp-module '<absolute-path-to-sharp>'
npm.cmd run scene-map:check
npm.cmd run research:sync
npm.cmd run build
```

生成器仅用 Node 内置模块排版 SVG，导出 PNG/轻量封面预览使用桌面工作区自带 sharp；没有增加项目依赖。`scene-map:check` 校验内容与 SVG、实际图片 SHA-256、PNG/SVG/预览同步、尺寸、来源版本和引用存在，并加入 prebuild。高清全图按用户打开/下载读取；统一首页只加载 960 像素宽封面预览。
