# 能力理解与产品扩展页验证记录

2026-10-10 验证了能力理解、七种产品方向与复用描述接入网页的流程。说明页使用真实实验截图，网页和生成的中文笔记共用 [产品方向 JSON](product-directions.json)。本次没有实现方向中规划的游戏、编辑器、多人通信或 AI 生成。

## 运行和构建

- 本地开发入口：`http://127.0.0.1:5180/directions.html`。研究街首页与技术实验页提供相互入口。
- `npm.cmd run build` 通过，输出研究街、技术实验、理解与扩展三个 HTML 入口及真实 Markdown、JSON 下载资源。Three.js 仍有约 545 kB 单块提示，构建成功。
- 构建前的 `content:check` 通过：6 项已有能力、7 个方向，稳定 ID、能力引用、场景关联、验证笔记存在和生成笔记一致。
- `npm.cmd run test:lab` 通过原有 27 组布局与统计检查。本次新增说明页，没有重新采集场景性能基准。
- 根目录 `npm.cmd run check` 与 `git diff --check` 通过。

## 浏览器流程

工具控制的 Windows Chromium 浏览器中，逐项点击七个方向，详情标题、选中状态、URL 方向 ID、三项待补能力与三项完成条件均对应正确。樱花商业街、林间村落与小广场的关联链接匹配各方向。

四组筛选得到 7、2、4、1 个方向。切换筛选时保持一个有效选中项；浏览器返回和刷新可恢复 URL 对应的详情。首页的三个摘要读取共同数据，点击游戏摘要可直接进入对应详情，页面定位到方向区域。

说明页跳转林间村落实验，场景名称与 `#forest` 一致，再通过技术实验页的“理解与扩展”入口返回说明页。浏览器检查中未记录到页面控制台 warning 或 error。

## 子目录和实际下载

使用 `preview:path` 在规划的 `/1010_codex_project/001-sakura-crossing/` 子目录提供本机静态预览。说明页、真实截图、首页摘要与页面往返正常；Markdown、JSON 与 MIT 许可证指向该子目录下的构建资源。

通过浏览器实际点击两种下载：

- `sakura-product-directions.json` 可解析为内容协议 v1，包含 6 项能力和 7 个方向。
- `sakura-product-directions.md` 下载文本与仓库生成笔记逐字一致。

静态服务器为 Markdown 增加 `text/markdown; charset=utf-8` 类型。此项只验证本机子目录，没有执行部署或发布。
