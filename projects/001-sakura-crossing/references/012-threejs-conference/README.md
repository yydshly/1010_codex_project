## 完整中文摘要（2026-10-12）

### 定位与能力：完整雨夜作品，以及可提取的方法

固定版本是一套 Three.js / WebGPU / TSL 场景工程。源库组合 GPU 雨丝、水花、屋顶遮雨、路面反射与涟漪、车漆滑落水珠、玻璃雨开场、霓虹后处理和第一人称 BVH 探索；它的直接能力是实时呈现场景并允许观察和交互。

完整城市的效果还依赖模型、车辆、视频招牌、烟雾、飞行器、环境光、GTAO、Bloom、雾、统一色调与空间音效。单独的下雨算法只负责其中一层；城市丰富度与艺术设计不能由一个粒子模块自动替代。

本地已保留固定原城市场景，加入中文四效果面板、只看单项、参数与三机位；另写了程序化原创街区和不依赖城市素材的最小例子。原城市仅本机研究，公开页使用实拍和详细说明，不再分发它的素材。

作者当前在线站点可能比此 commit 更新。驾驶、任务、多人等按钮不能推定为本版本现成功能；本库也不包含你的内容后台、账号、云存档或商业业务。

### 模块与分工：九组职责，四个已提取 API

九组逻辑职责是：启动与宿主循环、场景/模型/灯光、相机与 BVH 控制、高度纹理、GPU 雨滴/水花、湿地镜像/雨纹、表面水珠、后处理与设备预算、DOM 说明/操作桥。它们是源码职责分组，不能把每一组都视为已发布的通用包。

Rain Kit 已提取 createWeather、createWetGround、createDropletMaterial、createWalkControls / buildModelBvh。四项各有宿主输入、参数、更新、开关与 dispose；同一实现用于原创研究台、独立最小消费者和樱花街接入。

宿主提供 scene、初始化后的 WebGPURenderer、camera、canvas、UV、地面和碰撞代理；模块管理自己的雨缓冲、渲染目标与材质。借用的贴图默认不释放，宿主共享几何/BVH/renderer 由宿主管理。

城市素材、固定中文面板、模型服务、内容收藏、故事和玩法不在 Rain Kit 中。樱花街只接入天气、湿地和漫游三项；水珠仍在最小例子中体验，风格与导览也尚未独立成通用包。

### 底层原理：GPU 并行计算与多次场景渲染

Three.js 管理场景、几何、相机、纹理和资源；TSL 以 JavaScript 节点描述材质与计算，由节点系统生成 GPU 程序；WebGPU 执行渲染与计算。中文 DOM 面板改变真实参数，不绘制三维效果。

降雨先用俯视正交相机把最高表面的世界位置写入半浮点高度纹理。GPU 用雨滴 XZ 查对应 Y，移动粒子、比较表面并重生，再用面向镜头的实例平面批量画雨线。delta 积分降低帧率带来的速度差；水花独立周期，并非每颗粒子碰撞事件驱动。

湿地通过镜像相机额外渲染场景，隐藏地面并使用斜裁剪，按粗糙度与强度混合反射。程序雨纹扰动法线和采样 UV；水珠则由掩码有限差分改变法线/粗糙度，影响高光。Rain Kit 水珠为独立原创椭圆图案，不复制原复杂拖尾或玻璃折射。

BVH 加速静态几何射线，控制器处理步行、蹲下、地面与墙体滑行。循环顺序为相机输入 → 高度/GPU雨 → 材质时间 → 世界矩阵 → 镜像 → 主渲染/后处理。高度图只保留最高面，镜像只按平面实现，漫游不是刚体引擎。

技术资产是现成可运行的天气、镜像、水珠、静态行走与生命周期接口。下一个项目从最小例子开始，先接正确的场景/相机/地面与版本，再调整视觉参数，减少重复验证同一底层方法。

### 接入与复用：明确宿主边界，再加入自己的场景

可复制完整模块目录或安装 @research/rain-kit@0.1.0 的本地 tgz；固定 Three.js 0.185.1 与 three-mesh-bvh 0.9.13。天气和节点材质使用 WebGPURenderer / TSL，传统 WebGLRenderer 项目需先适配，不能只换 import 就完成迁移。

先 await renderer.init()，创建自有场景/相机/碰撞体，再配置雨区与高度覆盖、地面 y/尺寸/贴图、物体 UV、行走地面与墙体。一次只有一个控制器驱动相机；观察模式启用前停用 walk。

雨量倍率、可见数量和容量不同：capacity 决定 GPU 分配与更新规模，count 控绘制数，不代表线性省掉计算成本。镜像分辨率、隔帧、高度覆盖和渲染像素预算需要按设备测量，默认值不是所有场景的最佳值。

停雨不自动停水珠或镜像，天气预设由宿主组织。退出先停主循环和输入，再 dispose 模块，最后释放宿主资源；更改静态几何需要 refit/rebuild BVH。最小示例与全量 API 在本页保留下载和完整原文。

## 技术底层与原理

**雨滴碰撞**：俯视正交相机把世界位置写进半浮点高度纹理；GPU 计算着色器移动雨滴，以 XZ 查询对应 Y，触及最高表面后回收重生。实例化平面批量绘制朝向镜头的雨丝。高度图是一种 2.5D 近似，不能完整解决多层空间或侧向风雨。

**湿地反射**：镜像相机再渲染一次场景，用斜裁剪面过滤地面以下内容。反射纹理按粗糙度混合到地面，程序化涟漪扰动法线与采样坐标。它是视觉合成，尚非真实流体模拟。

**表面水珠**：原创椭圆掩码驱动有限差分法线与粗糙度，不创建逐颗水滴几何。它演示上游材质思路，未复制上游的滑落图案、拖尾和玻璃折射。

**渲染分工**：Three.js 管场景和资源，TSL 以 JavaScript 节点描述着色器，WebGPU 执行渲染与粒子计算，DOM 承载中文说明和控制。半分辨率反射、隔帧高度更新与半分辨率 Bloom 控制成本。

详细代码数据流、源码证据与边界见 [研究笔记](notes/research.md)。

- **雨夜研究街**：为现有小街加入雨量、夜间招牌和湿地；需适配 WebGL / TSL 渲染接口。
- **产品材质展厅**：围绕自有车辆或产品切换干湿表面、灯光和镜头；需补产品信息与材质参数编辑。
- **天气实验台**：增加固定采样、设备预算和结果导出，形成可重复的效果比较。
- **轻量探索游戏**：已有 BVH 漫游基础，可继续补任务、存档与物体交互。

产品信息、任务与结果导出尚未实现，业务效果与商业收益尚未验证。

实际运行环境：Windows、Node.js 22.15.0、npm 10.9.2、Three.js 0.185.1、Vite 8.3.4；Codex 内置浏览器显示 WebGPU 后端。

```powershell
cd F:\codex_project\1010_codex_project\projects\012-threejs-conference\web
npm.cmd ci
npm.cmd run dev
```

`npm.cmd run dev` 同时启动研究台 5192 和原库 5195。首次运行从 GitHub 下载固定版本到忽略的 `vendor/` 并独立安装依赖；之后复用。仅启动原创实验用 `npm.cmd run dev:lab`，仅启动原库用 `npm.cmd run dev:upstream`。
