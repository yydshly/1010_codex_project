## 如何去掉场景耦合

原来的高度图与地面引用全局 performanceProfile、雨层、场景纹理文件；雨引用本地水花和固定容量。现实现移到包内部，预算由每个实例传入，纹理由包内程序生成，rain layer 常量独立。公共天气组合高度图与降雨，自动隐藏自己的雨组，用户只管理 update 与参数。

原 `src/upstream/`、`src/effects/` 和 `src/controls/` 的路径保留为薄转接，避免旧验证页和引用断裂；实现由包统一维护。原研究台直接使用 createWeather / createWetGround / createWalkControls，水珠也通过兼容转接调用同一实现。原库本机准备脚本复制新 walk.js 及参数工具，保留其完整城市和中文面板。

新增的资源接口包括湿地纹理借用 / 释放责任、水珠强度恢复、天气固定容量与可见数量上限、释放输入监听及重复 dispose。离屏渲染用 try/finally 恢复目标、MRT、覆盖材质、清屏与可见性，异常不应破坏宿主后续帧。

独立近景暴露了旧原创实验的底色问题：vec3(Color) 在当前节点实现中把 r/g/b 当 x/y/z，结果是黑色底色。改成 TSL color 节点后，样块底色与湿润细节都可见，并增加金属度与粗糙度配置。原库独立授权的水珠图案未复制到包内。

## 实际验收

1. **接口与碰撞**：15 项 Node 测试通过，包含 5 项原漫游碰撞、5 项原库控制桥、5 项模块容量、停雨、状态恢复、纹理所有权、水珠强度、资源清理和包内导入闭合检查。模块接口测试使用受控 renderer，不能视为 GPU 测试。
2. **独立源码示例**：浏览器 WebGPU 初始化通过。四项开关可用；停雨时水珠保持 100%，关闭水珠为 0%，近景表面变平滑。反射关闭后镜像消失。可见数量 500 / 2000 输入均生效，初始为 1500 / 2000。
3. **漫游与释放**：开启漫游从 `(0,1.65,9)` 按 W 4 秒，停在 `(0,1.65,0.18)`，被样块代理挡住。C 后眼高为 0.91；再次起身恢复 1.65。释放后效果对象从 2 变 0，按 W 0.8 秒位置不变；重新接入回到 2 个对象及 1500 可见雨滴，强度 100%。
4. **GPU 回读**：真实 1000 粒子检查有雨棚 / 移除 / 恢复三状态通过。高度分别为 3.1 / 0 / 3.1；棚内粒子分别 25 / 38 / 33，低于棚高分别 0 / 2 / 0。结果保存在 [module-gpu-check.json](module-gpu-check.json)。
5. **实际 tgz 消费者**：`npm.cmd run test:kit-consumer` 将真实包安装到忽略的 `.kit-smoke/consumer-PgRl2P/`，包导出和参数检查通过；独立 Vite 生产构建通过。浏览器打开该构建也显示雨、反射和样块，没有捕获 warning / error。安装包哈希与构建记录见 [module-consumer-check.json](module-consumer-check.json)。测试目录没有纳入源码或安装包。
6. **原研究台回归**：WebGPU 初始化、第一人称入口及实际按 W 移动通过，HUD 记录已行走 0.4 米，日志没有捕获 warning / error。原库完整场景构建通过，ENTER 后中文面板与四项效果仍可用；在原库街口按 W 1 秒，相机从 `X -138.6 / Z 34.2` 移到 `X -136.3 / Z 33.7`，warning / error 为空，证明原库也能使用抽取后的共享控制器。
7. **尺寸**：1280 × 900 为画布 / 侧栏；390 × 844 为纵向布局，文档宽 375（含滚动条的视口宽 390），无横向溢出，实际雨开关可操作。窄屏代码块的 grid 最小宽度溢出已修正；验收后恢复默认视口。

研究台与原库构建保留超过 500 KB 的 bundle 提示。窗口日志和瞬时 FPS 不是跨设备性能结论。真实手机硬件、WebGL2 兼容后端、多实例长期 GPU 内存、其他子项目的业务接入和公开部署尚未验证。

## 可带走的范围

目前天气模块实现降雨；降雪等扩展需要新粒子行为。高度图依旧是每列最高面的 2.5D 近似，反射依旧适用于平面；水珠是原创简化材质；漫游是静态几何的射线控制器。宿主继续管理模型、灯光、交互、后处理和 renderer 的最终释放。

代码来源与授权随包保留，原创部分尚未指定发布许可证，包保持 private / UNLICENSED。原城市素材和 CC 授权的复杂水珠继续留在忽略的 vendor，本地安装包没有这些内容。
