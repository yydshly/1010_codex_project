# 雨夜渲染：能力、原理与复用价值

研究日期：2026-10-11。上游：[ektogamat/threejs-conference](https://github.com/ektogamat/threejs-conference)。固定版本：`8cc20593b2270e2ce832e7b7b44356705daddec4`。

## 定位与能力

Threejs-Punk 是由工厂函数组合的 WebGPU / Three.js / TSL 场景工程。核心是雨夜街巷、湿润表面、霓虹后处理和 BVH 第一人称探索，适合拆解技术而不是作为业务平台直接接入。

上游能力包括：GPU 雨丝与水花、基于高度纹理的降雨碰撞、地面程序化涟漪和平面反射、车身滑落水滴、玻璃雨开场、视频招牌、GTAO、Bloom、雾与调色预设、烟雾、飞行器、空间音效、漫游碰撞、设备性能预算。

初版页面只复现渲染核心。当前已增加原库本机完整体验和原创街区的第一人称漫游：固定原库含原始模型、视频、音效、GTAO、玻璃开场；原创实验改编 BVH 控制器，保留几何、程序纹理与独立水珠。观察模式仍是 OrbitControls，镜头导览与第一人称模式独立，见 [漫游升级记录](walk-upgrade.md)。

原库完整城市也已接入中文控制面板：四项效果直接调用原渲染对象的接口，可漫游、单项隔离、定位近景、调节参数并查看原理。水珠独立于降雨，法线随有效强度收零；辉光同时控制设备预算允许的镜头光晕。接入方式、实际验收与限制见 [原库中文控制面板](upstream-controls.md)。

天气、湿地、原创水珠和漫游现已提取为 Rain Kit：统一参数、更新与释放接口，实例独立预算，借用贴图所有权，附最小接入示例与本地安装包。原研究台使用同一实现，真实 tgz 已在独立目录安装、构建并打开；提取范围和验证见 [模块提取记录](module-extraction.md)。

作者在线站点此前观察到驾驶界面。在线部署可能与此固定版本不同；驾驶、任务、多人按钮不能推定为本仓库对应版本的已有实现。

## 底层分工

- Three.js：场景树、相机、几何、纹理、节点材质与渲染资源。
- WebGPU：渲染通道和计算着色器，更新 GPU 存储缓冲中的粒子。
- TSL：以 JS 节点描述材质、计算与后处理，由节点系统生成 GPU 程序。
- DOM：中文说明、效果开关、视角选择和当前窗口性能显示。

上游使用 `Fn`、`If`、`instancedArray`、`billboarding` 和 `RenderPipeline`。可复用接口主要是 `update`、参数 setter 和 `dispose`。

## 雨滴碰撞

俯视正交相机把附近场景最高表面的世界位置写入半浮点 RenderTarget。XZ 到 UV 的映射必须与高度通道一致；雨滴读取采样的 Y 后比较自身高度，触及表面时在上方重生。最近邻采样避免物体边缘出现混合高度。

帧顺序为：漫游/观察镜头更新 → 高度纹理 → GPU 雨滴计算 → 材质及街区动画 → 地面反射 → 主场景与 Bloom。高度通道隐藏雨滴、水花、原创蒸汽与飞行器；新增天空等对象时也需更新隐藏列表。

本地：高度图 384²，80 × 80 世界单位覆盖区；每两帧更新。GPU 缓冲按 5000 分配；控制面板改变雨丝和水花的可见实例数量，计算更新仍保留分配规模，不能把数量滑块解释为已验证的线性性能优化。

本地补充了 delta 积分。上游原实现每帧直接累加速度；本地乘以 `delta × 60` 并限制极端步长，减少不同帧率下的速度差。再生高度以碰撞面为下限，防止新场景的高楼超出固定再生区间。

高度图是 2.5D 近似，每个水平位置只保存一个最高面。多层空间、侧向风雨和壁面碰撞需要扩展。水花按独立周期在表面生成，并非由每颗雨滴碰撞事件触发。

## 湿地反射与涟漪

镜像相机沿地面反射主相机的位置、朝向和 up 向量。单独渲染倒影，隐藏地面，使用斜裁剪面去掉地面以下内容。WebGPU 的投影约定与 WebGL 不同，沿用上游分支处理。

倒影以半分辨率渲染、隔帧更新。地面材质把反射乘以 `1 - roughness` 加入 emissive，程序化涟漪扰动法线和反射采样 UV。它是一种视觉合成方法，不是完整的能量守恒水面模拟。

源码 `MAX_RADIUS = 1`，双循环范围 -1 至 1，实际采样 **3 × 3 / 9 个邻域单元**。上游文字文档写过 5 × 5 / 25 cells，与固定版本源码不一致，本研究以源码为准。

## 水珠材质与授权

上游滑落图案通过水珠掩码的有限差分改变法线，掩码同时降低粗糙度，UV1 与基础贴图 UV0 分开。上游图案源自 rocksdanister/rain / BigWings，另含 CC BY-NC-SA 3.0 条款，不能仅凭上游仓库 MIT 就将该图案视作全 MIT。

原创实验独立编写椭圆与周期滑动，没有复制原图案、拖尾或玻璃折射代码。原库本机副本保留原图案及其授权，只存于忽略的 `vendor/`，不随研究台代码发布。文件与授权见 [THIRD_PARTY](../web/THIRD_PARTY.md)。

## 对当前研究集的价值

樱花小街研究程序化几何、分段光照和描线，这个项目补充写实表面、天气、反射与 GPU 并行计算。两者可以共用场景组织和内容交互思路，但本地樱花小街采用 WebGL / ShaderMaterial，移植 TSL 材质需要明确渲染后端接口与版本。

建议先提取天气、湿地、风格三层；每层都有开关、参数预算、更新与释放接口。接入资料入口、展品信息或任务后，才形成完整产品流程。

| 方向 | 可带走的方法 | 待补能力 |
| --- | --- | --- |
| 雨夜研究街 | 雨量、反射、灯光与场景预设 | 与阅读收藏流程整合；WebGL / TSL 适配 |
| 产品材质展厅 | 水珠、粗糙度、镜头与光照对照 | 自有模型；参数编辑；产品信息 |
| 天气实验台 | 效果开关；半分辨率与隔帧预算 | 实机基准、可重复采样与结果导出 |
| 轻量探索游戏 | 上游 BVH 漫游和环境氛围 | 任务、状态机、存档、角色与交互 |

这些方向属于方案判断，商业效果、性能上限、触屏真实设备表现尚未验证。
