## 构建流程

在固定源码导入后的 `web/` 内执行 `npm.cmd ci --no-audit --no-fund`，安装 52 个依赖包。原始 `npm.cmd run build` 在 TypeScript 阶段失败，错误为 Ha-Go 辅助文件的重名与不可调用表达式。

按 [构建修复记录](build-fix.md) 局部改名后，`npm.cmd run build` 退出码为 0。TypeScript 检查通过，Vite 8.3.0 转换 615 个模块，生成 `dist/index.html`、`dist/harness.html` 和分块资源。日志中的 Vite 构建阶段约 1.74 秒，不包含整个命令的类型检查耗时。

本项目的 `npm.cmd run dev` 也实际启动成功，监听 `127.0.0.1:5199`；首页与 `/src/main.ts` 均返回 HTTP 200。开发启动检查后关闭该服务器，完整浏览器交互验收使用下面的生产预览。交付时生产预览仍在本机 5198 运行。

## 完整用户流程

用户流程为打开生产页面 → 从资产库筛选模型 → 选中并修改配置、数量和编队 → 移动、旋转、复制或删除 → 自动保存 → 刷新恢复。这个应用的状态与模型都在浏览器中，没有 API 或数据库边界。

执行：

```powershell
npm.cmd run preview
```

保持预览服务器运行，在另一终端的同一 `web/` 目录执行：

```powershell
npm.cmd run verify -- --screenshots ../assets --report ../notes/verification-results.json
```

## 数量、加载观察与告警

默认展台实际计数为人员 192、车辆 24、火炮 12、飞机 4、独立装备 48，总计 280 个模型、96 个组。界面显示总限制 300。

本轮 `catalogMs` 为 1088，`displayMs` 为 53862，页面 `readyAt` 为 59018 毫秒。目录发现与默认展台准备约需一分钟，是该电脑、独立浏览器配置和该次冷启动的观察。没有重复采样、GPU 计时、稳定帧率或跨设备比较。

浏览器运行错误与失败网络请求均为 0。日志有 X4122 浮点精度、X3595 梯度指令以及 `BufferGeometry.toNonIndexed()` 提示，原文已去重保存在 JSON 报告中；本轮没有改动这些上游渲染代码。
