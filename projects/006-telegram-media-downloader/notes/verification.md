## 已执行：受控下载源码实验

Node VM 执行固定版本原下载函数与 Stories 路由，真实本机 HTTP 返回自有素材字节；DOM、链接保存及文件系统 API 使用测试替身。12 项结果、方法与限制见 [download-testing.md](download-testing.md)。

- 正常图片 17,802 字节、视频 382,362 字节、合成测试语音 36,731 字节；保存前后 SHA-256 一致，FFmpeg 完整解码成功。
- WebK / WebA 图片 / 视频 Stories 共四个模拟 DOM 路由均注入按钮并保存对应完整文件；尚未访问真实 Stories。
- 视频 200 缺少范围头及 206 起点错配均中止。语音完整 200 保存成功；起点错配时却保存 8,192 字节的首段，哈希不一致。
- 截断 OGG 仍能解码和播放约 1 秒，原语音为 9.93 秒，说明可播放不足以证明完整。
- 排队写入替身中界面 Completed 早于关闭完成，close 调用时仍有 46 次待写入；最终文件完整，没有证明真实浏览器文件系统损坏。
- 9 项完整输出、2 项中止、1 项截断；这些是受控观察，不能推算真实 Telegram 成功率或吞吐速度。

图片链接 HTTP 读取由保存适配器完成，不是浏览器原生下载验证。上述输出文件与原始 JSON 已加入网页实验区；页面仍不连接 Telegram。
