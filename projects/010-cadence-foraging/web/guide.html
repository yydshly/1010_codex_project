01 / 能力与定位

一个库，两条已经运行过的学习路径

“输入 → 输出”关系由你定义。网络参数决定它怎样回答；真实反馈让参数改变。当前项目既有强化学习，也有监督预测，不能把两种任务当作同一种算法。

本机已运行

Brain · 学会选择动作

观察 → 神经活动与记忆 → 动作 → 环境执行 → 奖励 → 参数／联想记录更新。它学“遇到这种情况，选什么更有利”。

02 / 先分类，再比较

历史和 EP，不是二选一

历史、摇杆和地图是“看什么”；神经网络和物理模型是“怎么算”；监督／奖励是“怎么评判”；EP 和反向传播是“怎么获得参数调整方向”。输入可以组合，模型与学习机制也可以组合。

  1. 输入信息位置历史、当前速度、姿态、摇杆、场景、目标或预定航线
  2. 计算模型运动方程、反馈神经图、时序网络；带滤波的状态估计
  3. 学习目标监督：靠真实答案衡量误差；强化：靠行动后果衡量回报
  4. 学习机制反向传播、EP、Delta／Hebbian 规则、进化搜索；各有适用条件

输出也有选择：一个位置、一段轨迹，或多种可能的未来。增加多个候选不会自动得到校准准确的概率。

活动不是参数

活动是这次计算的临时数值；内部状态让近期历史影响现在；参数是学到的处理关系。预测一次不等于训练一次。

超参数不是学到的经验

学习率、网络宽度、扰动 β、求解预算由应用配置。连接权重、偏置或 A/B/C 矩阵才是训练修改的参数。

03 / Equilibrium Propagation

EP：用网络活动的变化形成学习方向

用一个实际样本看数字：为什么两侧相减？八幕动画 →一条训练鱼的 8 步 EP 计算 →正负扰动的九章推导与独立核验 →完整输入、自由态、扰动态、局部导数、参数变化及无答案重算；独立改变权重核对学习方向，来源为真实 Python 计算。

平衡传播研究互相反馈的网络怎样从误差学习。“平衡”是固定输入和参数下，内部活动趋于自洽；“传播”是输出端的小扰动影响内部活动。它不增加传感器，也不会知道未来的操作。

讲解示意 · 不是无人机实测，也不调用 Cadence

假设旧飞行记录的正确后续位移是 1.5 米，网络自由预测为 2 米。按下方步骤看教学与预测怎样分开。

1 / 4

图学习比较每条连接两端的活动乘积差；时序模块比较两条受扰动路径上的局部参数导数。当前 Cadence 采用中心对比，即 +β 和 −β 两次教学计算。

图连接的局部对比 ≈ (s⁺前 × s⁺后 − s⁻前 × s⁻后) / (2β)
+β、−β 是电脑里的教学扰动，不是两次真实飞行。

在奖励路径中，扰动围绕“刚刚选中的动作”建立，真实奖励随后决定强化还是削弱；正确路线不会提前输入。

对称的有效连接、稳定平滑分支、小扰动与充分求解等条件支持 EP 的梯度解释。当前 NPC 的扰动阶段是有限步计算；不能宣称每次更新都等于精确梯度或必然改善任务。时序模块求解成功也不保证测试预测准确。
还有哪些学习机制？怎样形成学习信号？用在什么地方？
反向传播沿计算图用链式法则计算参数对误差的影响常见神经网络训练；优化器再执行参数更新
Delta 规则根据目标与预测的差，结合输入修正参数简单线性预测、联想纠偏
Hebbian 学习根据两端共同活动改变连接建立联想；共同活动本身不保证任务误差下降
进化搜索尝试多组参数，按任务表现选择与变异不可微或需搜索结构／配置的研究；试验成本需计入

梯度是“该往哪里改”的信息；梯度下降、Adam 是使用该信息的优化器。EP 与反向传播主要比较学习信号的获得方式，不应与 Adam 混成同一层的替代品。

04 / 奖励学习

从街口选择，到终点奖励更新

  1. 观察与活动

    路牌与位置编码成数值。工作轨迹、联想记录参与输入，反馈神经图迭代计算活动。图求解合格才发出动作。

  2. Actor 选动作

    Actor 是动作选择部分。探索时将动作活动经 softmax 转成概率并抽样；当前 live 平静时使用贪心选择。

  3. 保存参与记录

    正负扰动为所选动作形成连接响应。资格迹记录近期选择涉及的连接，供晚到的奖励使用。

  4. 环境执行，结果回来

    Critic 估计状态的回报；TD 误差比较实际奖励和下一状态价值与原先预期。结果可能比预期好，也可能差。

  5. 改变参数与联想记录

    调制后的预测误差乘资格迹影响连接；Critic 与联想记忆有各自更新。下一次选择才可能改变。

TD 误差 δ = r + γ × V(下一状态) − V(原状态)
终点不加下一状态价值；本配置对 TD 信号有截断。
参数变化 ≈ 学习率 × 调制后的 TD 误差 × 资格迹

例如原来预计 0.5，单步终点实际得到 1，误差为 +0.5；实际得到 +0.2，误差为 −0.3。正奖励也可能低于预期。这些数字用于解释公式，不是实验读数。

工作记忆：记住刚才看见什么

近期活动的衰减轨迹参与下一次输入。它不是准确存储路牌文字的变量，保留能力要实测。

资格迹：晚到奖励应该影响谁

它记连接对近期动作的响应，不负责保存任意观察。记路牌与把奖励分给街口选择是两个问题。

联想记忆用观察键读取动作结果联系，实际执行的动作才有结果；当前默认键来自原始观察，相同观察可能混合不同历史。唤醒机制调节探索与学习频率，“唤醒”是软件状态，不表示情绪或意识。

当前路线图有 42 个神经元、450 条有向连接。wait 可改变活动轨迹，但不把“奖励还没到”当成零奖励，也不替换待奖动作。done 清理临时回合状态，保留学到的参数。当前 Critic 使用 modulated 信号，不能直接当作已校准的标准期望回报。

05 / 对照基线

Q-learning：给状态与动作记一张价值表

Q(s,a) 表示“在状态 s 选择动作 a，预计能获得多少折扣回报”。当前对照由本项目实现，不是 Cadence 默认 Brain 的底层 Q 表。

Q(s,a) ← Q(s,a) + α × [r + γ × max Q(s′,a′) − Q(s,a)]
终点：目标只有 r，不跨回合取下一状态价值。

α 是新结果影响旧估计的速度；γ 表示未来回报的权重；ε 是随机探索比例。假设 γ=0、旧 Q=0.4、奖励=1、α=0.3，则新 Q=0.58。这个值不等于环境的完整地图。

控制器保存什么？怎样改变选择？
规则人工定义的规则与少量状态命中复访、落空巡查；规则本身不训练
表格 Q-learning状态 × 动作的价值数值用实际反馈更新 Q，通常选高价值并保留探索
Cadence Brain图参数、Critic、工作轨迹与联想记录活动形成策略，反馈调制局部学习与记忆

四店只有一个固定观察和四个 Q 值。街区对照锁存看过的路牌，共 6 个状态、12 个 Q 值；规则也保留路牌。比较时必须给基线适当记忆，不能故意削弱它们。当前数据没有证明 Cadence 总体胜出。

06 / 预测与学习分开

捕鱼：复盘旧轨迹，预测新轨迹

当前捕鱼是监督时序回归，不根据命中奖励训练。输入为九个历史位置计算出的速度／加速度特征：7 个时刻 × 4 个数。真实 TemporalPatchNet(4,8,24) 输出 12 个未来时点的二维位移。

hₜ = A tanh(hₜ₋₁) + B uₜ
yₜ = C tanh(hₜ)
A：历史状态怎样影响现在；B：输入怎样进入状态；C：状态怎样读出预测。
共 288 个可训练参数；输出换算成位置由本地应用完成。

训练用已采集旧轨迹的未来位移作答案，以平方误差评判。残差预测编码为时间关系与输出的不一致建立误差；教学阶段用阻尼 Newton 方法求解正负扰动路径，再作 EP 参数对比，不对 Newton 迭代反向传播。求解器计算活动，学习规则修改参数。

每条件 192 条不同训练轨迹、48 条留出轨迹；192 批、每批 8 条允许重复抽样，是 1536 次抽样，不是 1536 条独立鱼。测试参数冻结，每条鱼从零隐藏状态读历史，未来只给评分和回放层。训练损失下降不保证留出误差下降。

07 / 不规则运动

你驾驶无人机：预测运动反应，还是猜下一次操作？

无人机正在向前飞，下一刻你可以保持摇杆、向左打杆或松杆减速。相同的过去可以接不同操作；如果新操作尚未输入，历史位置无法确定你的临时决定。连续转弯、加减速也可能包含规律，关键在于变化是否有可观测的线索。

建模条件说明 · 尚未用真实无人机日志验证

有机会学到

松杆后的惯性、转向响应、操纵到运动的延迟，以及相似条件下重复出现的习惯。需要数据覆盖和留出验证。

输入仍可能缺少

下一秒临时改变的操作、未观测阵风、新目标。加入当前摇杆，也不等于知道未来摇杆。

训练方案可设为“最近一段状态与已发出的操作 → 未来 0.2／0.5／1 秒位置”。这些是候选评估时长，不是准确度承诺。需明确假设：未来保持当前指令，还是按历史操作习惯估计。计划航线表达意图，也不保证实际轨迹完全一致。

左转和右转都合理时，平均成中间位置可能掩盖两种不同未来。多条候选或范围更有解释力，但当前演示没有概率预测；须另行设计并校准。

可以研究延迟期间的位置估计、回放分析、操作响应建模。本项目没有无人机数据、精度结果或飞控接入验证。不能把捕鱼成绩换算为无人机性能。

操作与模式参考：PX4 v1.16 摇杆到运动指令的映射；此处 Cadence 无人机方案为建模推断。

09 / 场景与选择

把技术选择放到实际问题里

游戏 NPC、虚拟宠物

在有限行为菜单里，根据执行后的可靠反馈更新选择。Brain 可研究适应；任务可枚举且规则稳定时，先比较规则和 Q。小街实测支持这项比较，不支持 Cadence 普遍更优。

捕鱼与其他运动对象

只有位置且有重复运动结构时，可训练时序预测器；能读取脚本时，先利用脚本与几何模型。捕鱼证明能学部分趋势，尚未证明替换强基线的必要性。

你操纵的无人机

状态与已发操作用于短时响应预测候选实验。用不同飞行测试转弯与突变；目前只有建模分析。

模拟机器人、自适应装置

学习动作后果，或在有限选项中调整策略。时序与规划接口是研究候选；环境、编码、目标和执行由应用负责。

持续学习与记忆研究

分别测获取、工作记忆、旧技能保留、干扰、恢复与续跑。机制可读取是研究价值，不保证全面终身学习。

LLM 语言与工具推理、参数学习、轨迹预测和控制器是不同角色，可以由应用组合。当前 Cadence 接收你定义的数值，不会自动理解文本、地图或任务。

10 / 如何用

先定义闭环，再接接口

  1. 任务与输出

    选动作还是预测位置？多远的未来？输出维数、含义和执行由应用定义。

  2. 输入与时间顺序

    统一时间戳、坐标系、采样与尺度。只输入当时可知的信息；差分可以作特征，不读取隐藏状态。

  3. 真实反馈

    奖励给上一实际动作；监督给已采集记录的真实答案。等待不是零奖励，预测内容不是已见事实。

  4. 公平评估

    按不同轨迹／飞行划分训练与测试，避免相邻窗口泄漏。冻结评估多个时长，比较误差、回报与全部成本。

接口骨架：动作学习

from cadence import Brain
brain = Brain.compose(4, 2, modules=(16,), arousal=True)
action = brain.live(observation)  # observation 形状 (1, 4)
# 应用执行 action，取得 next_observation 与 reward
next_action = brain.live(next_observation, reward=[reward])
# reward 属于上一动作；应用负责执行、奖励和回合边界。

phase = net.imagine(test_features, state=np.zeros((batch, 8)))
# 检查 report.updated、phase.converged；再读 phase.output。
# 特征 (batch, 7, 4)，训练答案 (batch, 7, 24)。
