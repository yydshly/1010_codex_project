# Cadence 中文研究：持续学习与樱花小街觅食

研究日期：2026-10-10 至 2026-10-11。固定源码：`19bee92756d1842176ad30b1cd01edbfbfa3f14c`，包版本 `0.80.0`。

上游：[muellerberndt/cadence](https://github.com/muellerberndt/cadence)。本研究以固定源码为依据，网页上较旧的 0.78 / 0.79 安装提示不能作为本次版本记录。上游 GPL-3.0 许可证原文保存在本项目 `licenses/`。

## 1. 能力与定位

Cadence 是 Python 研究框架。默认 `Brain.compose` 把观察输入、互相反馈的处理区域、动作区域、近期工作轨迹和快速/持久联想记忆组合起来。同一个脑可以通过 `live` 接收前一动作的实际奖励，再发出当前观察下的动作；`step` 提供批量、明确教学与逐次奖励学习的控制。

它提供动作、参数塑性、记忆、内部状态检查、保存和恢复。可选观察区域在同一神经图中加入递归反馈；System 1、System 2 是软件角色，不能由这些名称推导出意识或人类水平的理解。

高级机制有各自边界：`TemporalPatchNet` 学习有限路径的环境变化，提供连续输入规划；`RecordPatchNet` 保留事件、补全提示并把固定补全结果用于睡眠巩固。它们没有全部整合到默认 Brain。默认 `imagine` 求解应用提供的假设观察，不会自行生成环境转移。

## 2. 实际效果与证据

2026-10-10 的前期本机研究运行了上游 `examples/continuing_brain.py`；保存后接收同一未决反馈的行动与检查点一致。相关测试 99 通过、2 个 Torch 分支因未安装该可选依赖跳过。这不是整个上游测试套件的结果。

同日对上游气味实验运行 3 个开发种子（0、1、2），A 暴露 300 次，随后 B 600 次与恢复 A 600 次。调参 `live` 的 B 阶段最后 100 次平均最优行动率为 1.00，反转延迟中位数 19；默认 `step` 约 0.50 且没有达到反转阈值；表格 Q-learning 为 0.96，反转延迟中位数 141。这是该任务上的小规模复现，不是独立确认或一般排名。

上游更完整的气味报告显示联想记忆是重要的适应来源，默认参数在此处表现较差。延迟钥匙—开门任务的历史完整目标未通过。因此应同时保留成功与未达标结果，不能把可运行演示当作普遍学习能力。

作者的 Atari、Rover Lab、Patch World 和音乐演示使用不同引擎；音乐网页使用预先学习的检查点，小车仍为模拟环境。本研究没有独立操作验证全部作者网页。

前期三种子气味实验的原始凭据保存在 [earlier-odor-receipt.json.gz](earlier-odor-receipt.json.gz)。其中协议含作者更大实验的说明，但本机只运行了凭据 `body.seeds` 中的 0、1、2，不能把协议里的完整确认集误认为本机结果。

本次自有觅食实验的运行结果与浏览器实拍记录在 [验证记录](verification.md)。四种子共 2400 轮，Cadence 总命中率 86.71%、规则 99.33%、Q-learning 88.00%；Cadence 每个阶段的最后 50 轮均为满命中。该任务中规则更快，体现了学习系统的适用边界。

## 3. 底层原理

神经图中每个单元保留势和活动，接收外部驱动与连接输入，反复放松到满足方程的状态。处理区域与动作区域之间有返回连接；动作读取求解后的动作活动，不能用单向前馈示意图代替实际递归。

图学习使用自由状态与正、负扰动状态的局部活动对比。每条突触比较两端活动乘积的变化，更新连接强度；默认路径不保存反向传播计算图。其梯度解释需要有效权重对称、稳定平滑分支、充分求解与小扰动等假设。默认有限教学阶段与严格合格教学不是同一保证；其他引擎也有独立更新规则。

奖励路径结合实际结果与预期价值的差异以及资格迹。联想记忆另用误差修正规则写入观察—实际动作结果关系。`live` 用脑内唤醒状态选择平静的贪心行动或探索与学习；成功也可能在年轻或持续唤醒阶段被学习，并非只在失败时更新。

数值合格只说明方程得到满足；命中食物才是外部任务证据。工作迭代、训练阶段、记忆访问与物理电能必须区分，不能从残差或数学能量推断节电优势。

## 4. 使用场景

- 游戏 NPC、虚拟宠物：从明确的行动后果学习有限行为选择。
- 模拟机器人：学习动作与观测运动，研究环境或身体变化后的适应。
- 自适应交互装置：在有限行为菜单中根据可靠反馈更新策略。
- 持续学习研究：分别测量获取、旧技能保留、干扰、恢复与保存后续跑。
- 时序与创意实验：借助高级引擎探索音乐或动作序列，独立判断结构与质量。

现有证据不支持直接宣称通用语言理解、普遍迁移或成熟的终身学习。接口处于 Alpha，参数与版本应固定。

## 5. 可扩展方向

先把环境观察、实际动作、奖励和时间顺序接正确，再增加能力。街区线索、稳定子任务回查、两个岔口及等待反馈现已实现并实际运行，结果见 [新场景研究](route-research.md)：本配置未表现出总体优势，短暂线索与稀疏奖励还有明显失败。后续加入更多线索与未见组合、长延迟、障碍与连续路程，仍保留强规则及适当的有记忆学习基线，检验是否值得增加复杂度。

环境预测与默认持续脑的整合、按受影响关系局部修复、合格状态复用与低常规成本仍是上游研究方向。增加宽度、观察区域或加速后端，需要行为收益和完整成本测量支持。

## 6. 对当前研究集的价值

001 的程序化街景适合展示学习过程；002 的行动—结果闭环适合定义奖励。Cadence 补充修改图参数与联想记录的持续学习路线，可以与已有模型提示词记忆作区分。

本演示把三个控制器放在同一概念环境的三个独立副本中，不抢同一份食物。三渲二画面复用 001 的分段光照方法，新增四家店与三个几何角色。角色的步行只是行动结果的表现，控制器未学习路径。

简单巡查规则可能在这个任务中更好。这意味着本实验适合观察机制差异，并帮助判断引入学习系统是否值得；不能为突出 Cadence 而故意削弱规则。

## 本地实验定义

每轮固定观察 `[[1,0,0,0]]`，四个动作分别选择四家店。食物坐标、阶段编号和迁移通知不传给控制器。命中 +1，落空 −0.25。每个控制器根据自己上一行动的实际反馈选择下一行动。

- Cadence：真实 Python `Brain.compose(4,4, modules=(16,), arousal=True)`；工作轨迹幅度 0（本任务没有相关前一线索）、巩固率 0.25、actor η 0.1、bias η 0.01，其余保留组合默认值。图参数与联想记忆均保留，迁移时不重建。
- 规则巡查：命中后再去该店，落空后按 0→1→2→3 顺序巡查。初始动作 0；规则本身为人工给定。
- Q-learning：单个固定状态、四个 Q 值；`Q[a] += 0.3 * (r + 0.9 * max(Q) - Q[a])`；ε=0.12，并列最高值随机选择，初值 0。

自动实验第 1–200 轮食物在团子店，第 201–400 轮在饭团店，第 401–600 轮返回团子店。手动迁移关闭后续自动切换，保留所有控制器状态，最多运行 1000 轮。重新开始才重建控制器。

近期命中率是最后最多 30 轮的命中均值。曲线保留全部实际行动；加速动画只显示当前批次的最后一轮。显示的 Cadence 选择概率是该时刻的行为分布；神经活动来自实际自由状态。每轮延迟包括反馈处理与下次行动，排除 HTTP、绘图和步行；不是总系统成本或电能。
