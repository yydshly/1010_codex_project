## 1. 我们理解了什么

### 历史轨迹只是输入的一种

你可以输入位置，也可以输入设备温度、游戏局势、已发操作或数值化线索。输入必须由应用采集、编码；库不会自动读懂视频、语言、地图或业务。

### “新的轨迹”有三种意思

预测同一对象的下一个时刻；把训练经验用于一条没有参加训练的轨迹；迁移到新对象或新运动规则。我们验证了前两种的有限例子；第三种还需要单独的迁移实验。预测不是检索一条旧轨迹来复制。

### 学习的是可重复的关系

监督任务把“输入与真实答案的联系”写入参数；奖励任务把“观察下哪些动作产生更好结果”写入策略与记忆。最近活动、资格迹和长期参数承担不同职责。

### 不规则不等于没有规律

连续转弯、惯性、操作延迟或模式切换可以包含统计结构。下一次独立随机变化、临时决定而未输入的操作，不能由相同历史唯一确定。结果可能需要多条候选或范围；当前捕鱼只有点预测。

### 库、算法和业务是三个层次

Cadence 是提供若干模型与学习机制的实验性库。EP 是其中一种参数学习方法；业务还需要数据、目标、执行与评估。监督预测不因为采用 EP 就变成强化学习。

四类任务：预测 / 判断、动作 / 奖励、记忆 / 回查、动作后果 / 规划。监督输入真实答案；奖励输入执行后的评价；记忆接真实字段；规划要先有可靠后果模型、可控输入和明确目标。

## 2. 核心算法与机制

这些分组可组合，不是互斥产品，也不是把全部导出接口逐项称为独立算法。

### 1. 反馈神经图与稳定态计算

- 所属层次：模型 / 推理。模块：NeuralGraph、Brain、PatchNet。
- 本质：神经单元根据输入和彼此活动反复调整，直到满足该模型的方程，或耗尽预算。它计算这次回答；仅做计算不会自动留下学习经验。
- 例子：NPC 的路牌输入影响联想活动，联想区与动作区反馈后得到动作偏好。
- 适用：想研究反馈网络、局部信息交换、状态与记忆如何共同影响回答。一般分类 / 回归还要定义端口、监督和损失。
- 边界：内部方程满足不等于答对。不同 API 的停止规则不同；定向连接不自动满足对称能量模型的梯度条件。
- 公式 / 实现：示意：v ← v + dt·(输入 + W·s + 偏置 − v)，s = 激活(v)。Brain 发出动作前检查完整方程残差。

来源：[模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md) · [局部对比学习](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/learning.md)。

### 2. EP · 平衡传播与正负局部对比

- 所属层次：参数学习。模块：Learner、PatchNet；TemporalPatchNet 的时序版本。
- 本质：同一输入和旧参数先算自己的回答，再用已知答案轻微正向、反向影响教学状态。比较连接相关量的变化，估计参数调整方向。答案只参与教学。
- 例子：捕鱼的正负教学路径给出 C[2,0] 的中心对比 −0.0003250699414，学习率 5 使权重增加约 0.00162535。这个具体算术只对应已保存的一次训练。
- 适用：局部学习机制研究，数值监督任务，及反馈网络中的动作参与量估计。
- 边界：奖励路径的扰动目标是刚选中的动作，不是预先知道的正确答案；后来奖励才决定如何调制。图上的活动乘积对比与时序模型的能量参数导数不是同一公式。梯度解释需要相应方程、稳定光滑分支和小扰动；有限迭代奖励路径不能宣称精确梯度。
- 公式 / 实现：时序版：G估计 = (∂E(s⁺)/∂θ − ∂E(s⁻)/∂θ)/(2β)，θ ← θ − η·G估计。两侧不是两个实际环境动作，也不是随机给权重加减噪声。

来源：[局部对比学习](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/learning.md) · [时序预测与规划](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/temporal.md) · [模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md)。

### 3. 时序残差模型与整段教学修复

- 所属层次：时序模型 / 数值求解。模块：TemporalPatchNet。
- 本质：自由预测按时间向前计算。学习时，已观测答案引起的差异在有限窗口内共同修复，让后续误差影响更早的隐藏状态，再形成 EP 参数对比。
- 例子：当前捕鱼输入 7 个历史特征时刻，每刻 4 个位置差分特征；每刻输出 12 个未来时长的 x/y 位移，共 24 项。
- 适用：轨迹、操作响应、传感器趋势，以及短暂线索影响后续输出的有限时序任务。
- 边界：跨时间的密集隐层块求解有计算成本；窗口前的初始边界固定，不对更早调用求导。当前实现是 NumPy CPU，不能直接套用图引擎的设备加速结论。
- 公式 / 实现：自由态：h[t]=A·tanh(h[t−1])+B·u[t]，y[t]=C·tanh(h[t])。教学使用带阻尼的 Newton / 块 Hessian 求解、残差与分支检查；不是只靠一条连接的乘法完成全部训练。

来源：[时序预测与规划](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/temporal.md)。

### 4. Actor–Critic · 策略与价值估计

- 所属层次：奖励学习框架。模块：Brain、ActorCritic。
- 本质：Actor 决定做哪个动作，Critic 估计结果会有多好。真实结果好于或差于预期时，改变参与选择的参数。
- 例子：小街有四个动作“选店”，或两个动作“选岔口方向”；环境执行后才给各自的奖励。
- 适用：应用能列出可执行动作，又能取得可信反馈；例如 NPC 行为、模拟策略或有限参数档位。
- 边界：奖励定义由应用负责。随意增加奖励可能学到刷分行为；本地任务未证明比规则 / Q-learning 更好。
- 公式 / 实现：动作概率可由 softmax(动作活动/T) 得到。参数改变量还受 TD 信号、资格迹、掩码与具体优化配置影响。

来源：[奖励与资格迹](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/reward.md) · [模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md)。

### 5. TD · 时序差分误差

- 所属层次：反馈信号。模块：ActorCritic 的 Critic。
- 本质：把“这次拿到的奖励 + 下一状态估值”与“行动前的估值”比较，表示结果比预期好或坏多少。
- 例子：预计这条路线很好，实际落空，就需要降低旧偏好；即便得到正奖励，也可能低于原先预期。
- 适用：回报分步到达、需要边行动边修正预期的任务。TD 是学习信号，不是一个独立业务模型。
- 边界：终止回合应停止向下一回合自举。当前 NPC 的 Critic 使用截断调制信号，不等同于已经校准的标准期望回报。
- 公式 / 实现：δ = r + γ·(1−done)·V(next) − V(old)。γ 表示未来回报折扣；它不自动对应秒数。

来源：[奖励与资格迹](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/reward.md)。

### 6. Eligibility trace · 资格迹

- 所属层次：延迟信用分配。模块：ActorCritic。
- 本质：保留近期哪些连接参与了选择，后来的实际奖励到达时，再按这些参与记录分配影响。
- 例子：先在街口选方向，再选巷口，最后才知道有没有食物；终点反馈能够影响前面的选择。
- 适用：多步行动后才出现结果的任务，尤其需要明确“奖励属于哪个已执行动作”。
- 边界：资格迹不等于记住路牌；保住信用归属也不保证策略学得好。当前 wait 不把“尚无结果”当零奖励，也不额外按秒衰减。
- 公式 / 实现：E ← γλ·E + 本次局部参与量，参数变化由调制后的 TD 信号乘 E。当前街区 γλ=0.72。

来源：[奖励与资格迹](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/reward.md) · [模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md)。

### 7. Trace · 工作活动轨迹

- 所属层次：短期状态。模块：Trace、Brain。
- 本质：把最近神经活动平滑保留，再输入下一次计算。它让当前回答可以受到刚刚看过内容的影响。
- 例子：路牌离开视野后，仍尝试用近期活动区分樱花路线与灯笼路线。
- 适用：暂时可见的线索、短历史依赖、跨观察的上下文研究。
- 边界：它是一组连续数值，不是可靠的“路牌名称变量”。本地关闭轨迹的对照没有证明收益；明确可编码的线索也可直接用状态变量记住。
- 公式 / 实现：c ← d·c + (1−d)·h，再以幅度系数输入后续网络。清活动与清学习参数是不同操作。

来源：[工作轨迹与联想记忆](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/memory.md)。

### 8. Delta 纠偏与两速联想记忆

- 所属层次：局部关联写入。模块：SynapticMemory。
- 本质：用线索读出已有的结果估计，真实结果到达后写入“真实值减已有值”的纠偏。快部分响应近期变化，慢部分保留较长期关联。
- 例子：某种街区观察与某个已执行选店动作的实际结果相联系；未执行动作的结果保持未知。
- 适用：数值线索到结果的快速关联、重复环境变化、与慢模型组合的记忆研究。
- 边界：默认 Brain 记忆键来自原始观察，相同观察可能混合不同历史。有限容量会干扰；不是自动保存所有事件的数据库。
- 公式 / 实现：基本形式 M ← M + rate·outer(k, v−kM)；具体实现另有归一化、快慢矩阵与写入掩码。它不需要 EP 的两次扰动。

来源：[工作轨迹与联想记忆](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/memory.md)。

### 9. Records · 稀疏线索编码与局部记录读写

- 所属层次：事件关联 / 记忆。模块：Records。
- 本质：应用定义事件的数值字段，以线索码读写字段关联。读出可以补全部分字段，但是否属于真实经历必须由应用保留来源。
- 例子：在模拟宠物中，给定活动与环境线索，回查过去实际执行后的状态变化；这是候选设计。
- 适用：受控事件记忆、线索补全、快写入与干扰测试。
- 边界：不是 SQL 精确查询或文本语义 RAG。记录可能干扰，猜测出的结果不能当作真实见过的结果。
- 公式 / 实现：固定稀疏线索码 + 读出 + 局部 Delta 写入；具体字段、维数和写入率由应用与模块配置声明。

来源：[工作轨迹与联想记忆](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/memory.md) · [记录、上下文与巩固](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/record-patch.md)。

### 10. 门控时序上下文、显式反向求导与巩固

- 所属层次：时序模型 / 参数学习。模块：RecordPatchNet。
- 本质：按时间扫描上下文并读取局部记录；observe 对这条计算路径做显式反向求导更新慢参数。另有记录写入，以及可选的固定补全内容训练。
- 例子：研究新事件先写快记忆，再让慢模型逐渐吸收重复关联；需要检查旧事件是否受影响。
- 适用：事件序列、快速记忆与慢模型的组合、补全和保留研究。
- 边界：observe 默认不是 EP。detune 是另一项独立教学接口；sleep 不验证补全真实性，也不保证消除遗忘。
- 公式 / 实现：Adjoint 是反向模式求导，即使源码用 NumPy 手写而没有 autograd。局部记录写入与慢参数梯度更新要分开看。

来源：[记录、上下文与巩固](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/record-patch.md) · [模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md)。

### 11. 动作转移 + 有限证据修复

- 所属层次：状态推断 / 时序学习。模块：BeliefPatch。
- 本质：先按动作推进内部状态，再用新观测反复纠偏固定次数；从修复后的状态读出，并可对这些迭代和时间路径做反向求导。
- 例子：模拟对象在观测不完整时，利用动作与新读数维持一个可预测后果的内部表示；这是研究候选。
- 适用：部分观测、动作条件预测与证据融合的受控实验。
- 边界：Belief 这个名字不代表已校准概率。内部 latent、最后一步移动量不等同于 Kalman 的协方差或全局收敛证明。
- 公式 / 实现：转移 → 固定预算的非线性 repair → 读出；学习为穿过这些有限计算步骤的 adjoint。

来源：[有限证据修复](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/belief.md) · [模块与数值契约](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/contracts.md)。

### 12. 在已学模型中优化可控输入

- 所属层次：规划 / 控制候选。模块：TemporalPatchNet.plan。
- 本质：保持模型参数不变，在应用声明的动作端口与边界内调整候选控制序列，让模型预测更接近给定目标；用不带答案的因果重放检查预测成本。
- 例子：上游一维有界物体例子：先学动作如何改变位置，再选择控制让物体趋近指定位置。
- 适用：模型已能预测动作后果、有明确目标与可控变量的模拟实验。
- 边界：模型里成本下降不保证现实执行成功。目标和动作边界由应用给出；默认 Brain.imagine 不会自动生成已学环境转移。
- 公式 / 实现：先学习 f(状态, 动作)→后果，再搜索允许的动作输入。执行第一段 → 测量真实结果 → 更新条件 / 重规划；它与直接用奖励学策略是两条路线。

来源：[时序预测与规划](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/temporal.md) · [学习动作后果的交互示例](https://github.com/muellerberndt/cadence/blob/19bee92756d1842176ad30b1cd01edbfbfa3f14c/docs/interaction.md)。

辅助与高级方向包括 Arousal、保存恢复、TemporalMemory、Steered / Life / Governor、观察者及多 Patch 端口组合；各自契约不同，本页没有逐一运行验证。学习率、β、衰减、阻尼和求解预算是配置 / 数值策略，不自动提供新信息或语义能力。

## 3. 场景和业务设计

以下价值与最小原型为本项目应用推断。候选不是已实现业务，上游示例不是本机成绩。

### 1. 捕鱼 / 运动目标短时预测

任务：预测 / 判断。状态：**已有本地场景验证**。

看到一小段过去，鱼接下来更可能在哪里？

机制：时序残差模型与整段教学修复；EP · 平衡传播与正负局部对比。

- 输入：仅历史位置的差分特征。当前演示 0.4 秒历史；隐藏速度、未来随机数和未来真实位置不进入推理。
- 输出：未来 1.2 秒内 12 个时长的二维位移点，再由游戏计算瞄准与碰撞。
- 反馈：训练鱼的真实后续位置。按整条鱼划分训练与留出；未知鱼预测时不传后续答案。
- 可能价值：在重复运动统计下减少预测误差，帮助研究瞄准提前量；命中率还受弹速、碰撞半径和射击时机影响。
- 简单对照：匀速、匀加速度、零位移；若游戏掌握运动脚本，先比较脚本推演。
- 失败边界：完全独立随机变化没有可提前确定的方向。模型学到均值收缩也可能不如零位移；平均误差低不保证命中更多。
- 最小验证：保留现有两条件演示，下一步只改变预测时长和弹速；冻结留出模型比较误差、命中和耗时，再增加未见运动模式。

五步闭环：

1. 先采实际执行的状态 / 动作 / 后果序列训练模型。
2. 给定当前状态与目标，plan 调整声明的可控端口。
3. 应用执行允许的第一段动作，不把整段预测当现实。
4. 测量实际状态，比较目标偏差与预测偏差。
5. 把真实后果用于后续训练；按新状态重规划，参数与控制输入分别管理。

### 12. 模拟环境调节 / 温控与资源档位

任务：动作后果 / 规划。状态：**业务候选 · 尚未实测**。

在舒适、响应与资源成本之间，怎么选择允许控制？

机制：时序残差模型与整段教学修复；在已学模型中优化可控输入；Actor–Critic · 策略与价值估计。

- 输入：模拟室温、外温、负载、设备档位和已知控制；未知未来外部变化需要假设。
- 输出：下一档位或有界控制序列。可比较直接奖励策略与先学后果再规划两条路线。
- 反馈：实际模拟温度变化、耗用与目标偏差；单位和权重必须明确。
- 可能价值：探索随环境变化调整策略；把模型误差、控制目标与计算开销分开衡量。
- 简单对照：阈值滞回控制、PID、已知热模型 + MPC。
- 失败边界：多目标评分容易掩盖某项变差。温度数据能预测不等于能正确控制；模拟结果不能直接推定现实节能。
- 最小验证：先做简单热模拟，对相同扰动测试目标偏差、能耗、开关次数和 CPU 成本；新工况与新参数单独留出。
- 证据状态：未实现温控场景，未测节能比例。

五步闭环：

1. 声明状态、可控档位和目标。
2. 直接策略选档，或后果模型内搜索候选。
3. 模拟器执行允许控制。
4. 读取温度、耗用和目标偏差。
5. 监督后果模型或更新奖励策略，分别记录两条路径成本。

### 13. 事件回查 / 快记忆与慢模型研究

任务：记忆 / 回查。状态：**上游机制 / 示例 · 本地未接入**。

刚发生的事能否快速保留？相似线索会不会覆盖旧事？

机制：Delta 纠偏与两速联想记忆；Records · 稀疏线索编码与局部记录读写；门控时序上下文、显式反向求导与巩固；动作转移 + 有限证据修复。

- 输入：受控事件的数值字段、线索、已执行动作和真实后果；来源身份独立保存。
- 输出：线索对应字段的估计 / 补全，或利用新证据修复后的隐状态读出。
- 反馈：真实事件字段；可选巩固训练需固定并标记所用补全，不把它们当新增事实。
- 可能价值：研究一次写入、干扰、快速适应、旧知识保留，以及工作状态和长期参数的不同作用。
- 简单对照：字典 / 数据库精确记录、最近事件缓存、同容量联想器。需要可靠事实查询时先用精确存储。
- 失败边界：近似补全可能错误。sleep 不验证真实性；“有记忆”不等于不遗忘，不等于语言知识库。
- 最小验证：给重复与冲突线索写入事件，测获取、干扰与恢复；分别关闭快记忆 / 巩固，并保证来源可追溯。
- 证据状态：上游模块与示例；本地 NPC 只验证了默认 Brain 相关写入，没有运行完整 Records / RecordPatch / Belief 业务。

五步闭环：

1. 应用记录真实事件字段与来源。
2. 用部分线索读出关联或修复内部状态。
3. 应用把读出标成估计，事实仍由独立事件记录确认。
4. 取得真实字段后评分并纠正关联。
5. 比较局部写入与慢参数学习 / 可选巩固，对旧事件再次测试。

### 14. 异常线索 / 预测偏差提示

任务：预测 / 判断。状态：**业务候选 · 尚未实测**。

新读数是否明显偏离已经学到的正常变化？

机制：时序残差模型与整段教学修复；动作转移 + 有限证据修复。

- 输入：正常工况序列、可用控制与观测存在信息；工况切换要单独编码。
- 输出：模型预测及与新观测的偏差。报警阈值、故障类型与处置由应用定义。
- 反馈：真实读数与独立确认的正常 / 异常事件，分开用于训练和阈值校准。
- 可能价值：把重复正常模式转成可检查的残差提示，帮助回放与人工定位。
- 简单对照：固定阈值、滚动统计、简单预测残差；同误报预算比较检出。
- 失败边界：模型误差不等于故障；突然正常工况可能误报。持续在线学习还可能把异常吸收成“正常”。
- 最小验证：冻结正常数据模型，在有独立事件标签的留出段检验；分别报告误报、漏报和检测延迟。
- 证据状态：未实现故障检测，残差没有自动校准为异常概率。

五步闭环：

1. 用正常工况历史自由预测新读数。
2. 模型提供预测，而非直接给故障结论。
3. 新真实测量到达，应用对齐并算偏差。
4. 用独立标签判断提示是否正确。
5. 控制训练数据与阈值更新，防止异常被无条件学入正常模型。

## 4. 业务组合与外部方法

- 捕鱼是预测器 + 几何弹道 / 碰撞；命中不是靠奖励训练射击策略。若加 Brain 选射击时机，须另做实验。
- 宠物是应用提供需求、动作与评价 + 学习选择。动作差异不能直接推定更好的体验或理解情绪。
- 模拟机器人先监督学习真实动作后果，再规划候选控制。训练改参数，规划改输入，执行后测量才能判断效果。
- 异常线索是正常预测 + 应用算偏差、校准阈值与独立确认；预测误差不等于故障。
- LLM 可在外部承担文字理解、任务拆解与工具参数；Cadence 可承担一个数值预测或有限动作模块。本站未实现该组合。

本地已有规则 / Q-learning / 匀速 / 匀加速度 / 零位移对照。以下仅讨论，没有全部接入：上下文 bandit、Kalman / EKF / UKF、IMM、粒子滤波、GRU / LSTM、多候选预测、物理模型加学习偏差、PID / MPC。精确事实优先日志或数据库；未来独立随机变化不会因为换一个模型就能唯一预测。参见[方法地图](http://127.0.0.1:8190/guide.html#alternatives)。

## 5. 效果与证据

四店 4 种子共 2400 轮，Cadence 86.71%，规则 99.33%，Q-learning 88.00%；阶段末 50 轮 Cadence 平均 100%。街区每主条件 1440 趟，街口线索 + 终点奖励 40.56%，持续 + 终点 71.94%，街口 + 途中 74.31%，持续 + 途中 75.21%；没有测出总体优势，关闭 Trace 对照也没有证明其收益。

捕鱼每条件 192 条留出鱼，有惯性 Cadence 平均误差 75.57→17.72 px，匀速 21.34、匀加速度 20.25；命中 189/192，而匀加速度 190/192。独立随机时 Cadence 19.27 px，零位移 18.60 px。一条训练鱼的全部参数更新后某点误差 22.31→8.84 px，只说明那次训练，不替代新鱼评估。固定配置结果属于开发研究，未做独立确认或统计显著性结论。

完整数据与检查见 verification.md、route-verification.md、fish-verification.md，以及同目录原始评估 JSON。本轮未改参数、训练记录或成绩。

## 6. 实际接入

1. 定义最小任务、输出、成功指标与延迟预算。
2. 声明每个输入的含义、单位、时间、尺度与缺测方式。只输入当时可知信息；全零不是自动的“未知”。
3. 对齐真实答案或已执行动作的奖励、回合与结果 ID，晚到反馈只结算一次。教学 / 想象不写成事实。
4. 建立同输入、同反馈、同动作、同数据划分与预算的简单基线。
5. 选独立模块并读其契约。监督序列可选 TemporalPatchNet，有限动作可选 Brain；Records / RecordPatchNet / BeliefPatch 需另设字段和端口。
6. 检查输入形状、有限值、phase.converged、report.updated 或相应模块返回。失败尝试不能计为已接受更新。
7. 按独立对象 / 轨迹 / 会话 / 设备留出，测新任务、恢复速度、旧知识与总计算。续跑要保存完整组成，而非只一张参数表。本站尚未实现会话恢复导入。

接口骨架见 guide.html#usage 与 applications.html#integration；完整可运行代码在 runtime/experiment.py、route_experiment.py、fish_experiment.py。当前 Python 本机服务提供页面与模型，不调用外部 LLM API；没有公开部署。

## 7. 扩展优先级

1. 已有场景加时长、线索、未见组合，测同一模型条件切换后的恢复与保留。
2. 加已发操作、物理基线 / 偏差修正及记忆消融，确认哪个信息或机制贡献收益。
3. 设计多分支 / 范围输出，测覆盖与校准；当前捕鱼不具备概率预测。
4. 导入独立无人机或设备日志，或小型宠物模拟，先离线对照。
5. 一维后果学习与规划，再扩到更复杂受控环境；预测成本与实际执行成功分别评分。
6. 冲突事件、干扰、恢复与存档一致性，测真实长期保留。

直接研究价值是能检查学习如何发生并接受强基线对照；尚未证明通用性能、低功耗或商业收益。

上下文 bandit 的外部原理参考：[Vowpal Wabbit 官方教程](https://vowpalwabbit.org/docs/vowpal_wabbit/python/latest/tutorials/python_Contextual_bandits_and_Vowpal_Wabbit.html)。它在情境下选择有限动作，只观察已选动作的结果；本项目没有实现此对照。
