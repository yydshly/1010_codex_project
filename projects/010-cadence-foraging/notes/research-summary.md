# Cadence 完整中文理解与发布摘要

固定版本 0.80.0 / 19bee92756d1842176ad30b1cd01edbfbfa3f14c

Cadence 学习与记忆框架的完整中文研究：以既有总图引导，区分预测、奖励决策、事件记忆与动作规划四类能力；汇总12组机制与模块、EP正负扰动及真实数字、Actor–Critic/TD/资格迹、14个场景、个人价值和六阶段扩展。保留四店、街区与捕鱼的真实对照、原始资料、固定源码和授权；公开网页可回放计算与成绩，实时训练通过本机Python运行，未证明整体优于简单基线。

## 能力：学关系、选动作、存关联、预测后果

Cadence 是 Python 学习与记忆研究框架。你提供数值观察、允许的输出和实际反馈，它通过模型参数、工作状态和记忆调整后续输出。它不是已经懂捕鱼、无人机或用户意图的成品模型；框架、训练算法、具体模型和业务应用是四个不同层次。

第一类能力是有答案的预测或判断：用历史位置预测未来位移、用设备历史和操作量预测读数、把数值特征映射到判断。答案随后到达，用预测误差教学；这是监督学习。历史轨迹只是输入的一种，模型既不只服务个人轨迹，也不会因输入了历史就自动知道未来。

第二类是从实际行动结果学习选择：NPC 选店、选路、有限提示或工具路由。应用执行动作，再把该动作真正得到的奖励交回模型；Actor–Critic 根据结果与预期的差异调整选择。这类闭环属于强化学习。

第三类是保存和补全关联，第四类是先学动作后果再优化允许的控制输入。Records、RecordPatchNet、BeliefPatch 与 TemporalPatchNet 是有不同接口和训练方法的模块；不能把高级模块的能力都当成默认 Brain 已自动具备的能力。

## 模块：观察、神经图、策略、时序模型与记忆分工

Brain.compose 组织感觉、联想、动作等区域和递归反馈连接，配合近期工作轨迹、联想记忆、Actor–Critic 与唤醒调节。live 接收前一动作反馈并生成新动作；wait 在结果尚未到达时接收观察。观察编码、动作是否合法、执行和奖励定义仍由你的应用负责。

PatchNet 研究自由态和带教学扰动的平衡状态；TemporalPatchNet 将相邻时刻的残差关系连接起来，提供序列 observe 和受约束的输入 plan。捕鱼使用后一模块：4个差分输入、8个隐藏坐标、24个未来位移输出，共288个 A/B/C 参数。

Trace 保留短时神经活动，与负责延迟动作归因的资格迹不同。SynapticMemory 用快、慢联想矩阵和 Delta 误差修正；Records 用有限容量的稀疏线索码保存关联；RecordPatchNet 以显式反向求导学习因果扫描，并可用固定补全做巩固。

BeliefPatch 用实际证据有限步修复隐状态并以显式求导学习，不等于已经校准的概率滤波。plan 改的是声明为可控的输入，预测模型参数保持；sleep 不是事实核查。默认 imagine 求解应用给定的假设观察，不会自动生成完整环境转移。

## 原理与算法：求内部状态，再根据反馈改持久参数

神经活动是每次计算中的临时数值，权重是连接强度，标签是教学答案，奖励是动作的结果。首先固定输入和旧参数，求内部方程相互一致的自由状态，再读出预测或动作。内部残差小只说明方程求得好，不代表外部预测正确或任务成功。

EP（平衡传播）固定旧参数，用 F=E+βL 和 F=E−βL 分别重新求活动；E是内部不一致代价，L是与真实答案的预测损失。正负扰动改变教学作用和内部活动，不是给鱼的位置或权重随机加噪声。对同一参数取两侧局部导数，G≈(g⁺−g⁻)/(2β)，再按 w←w−ηG 更新。

两侧相减有用，是因为在可微、充分求解的同一稳定分支附近，带教学状态中局部参数导数随β的变化携带自由预测损失对参数的斜率。中心差分保留一阶响应并抵消共同项；不是任意两组活动相减都有效。互易/对称、平衡、β足够小等条件需按具体引擎核对，默认 Brain 的有限阶段不能一概等同严格 EP 梯度。

TemporalPatchNet 以相邻时刻的残差目标建模，教学时联合修复路径，本例用 Newton 联立求隐藏坐标；其 EP 对比用于 A/B/C 更新。奖励路径另外用 TD 误差 δ=r+γV(s′)−V(s) 和资格迹 e←γλe+c 分配贡献，经过调制、掩码和约束应用更新；联想记忆还走独立 Delta 路径。

Q-learning 是另一种强化学习基线：在状态—动作表上更新 Q(s,a)←Q(s,a)+α[r+γmax Q(s′,a′)−Q(s,a)]，再按探索策略选择。小状态空间容易检查。规则、Q、匀速、匀加速度与零位移是本项目对照；Kalman、IMM、粒子滤波和GRU/LSTM等是可考虑的外部路线，并非都由Cadence内置。

## 实际效果：三类任务、强基线与同一条鱼的更新

四店即时奖励：4个种子、2400轮、食物A→C→A。Cadence命中2081/2400（86.71%），规则2384/2400（99.33%），Q-learning2112/2400（88.00%）；Cadence每阶段最后50轮均命中。它会适应位置变化，但这个任务规则更快，不能由末段成功推断整体更强。

街区多步奖励：两类线索、两次岔口、等待及单线索迁移，24次运行共8640趟。四主条件的Cadence命中率40.56%、71.94%、74.31%、75.21%，规则均98.06%，Q为81.81%或84.24%。持续线索和途中反馈有帮助，本配置没有整体优势，关闭工作轨迹的对照也没有证明该轨迹收益。

捕鱼有惯性且随机转弯加速：只看0.4秒历史，预测1.2秒，4个种子各48条留出鱼。Cadence平均误差75.57→17.72像素，匀速21.34、匀加速度20.25；射击Cadence189/192、匀加速度190/192。预测误差较小不保证命中率最高，两种指标必须分别看。

完全独立随机运动：Cadence19.27像素，零位移18.60；命中162/192和167/192。模型能学到少外推的统计策略，但不能预知下一次独立随机选择。已有固定留出集用于开发观察，不是新的独立确认集，不以这些数字宣称普遍优势或统计显著。

同一条训练鱼的EP核验：C[2,0]的G约−0.00032507，学习率5令该权重−0.3654595952→−0.3638342455。实际288项更新使损失0.02595518→0.01726395，该点误差22.31→8.84像素；仅改这一项时约22.30像素。训练样本变好与留出泛化是两个证据，网页保留所有实际端点和独立数字核验。

## 场景与业务：先确定输出和反馈，再选算法

已测场景是四店NPC、街区多步NPC、历史位置捕鱼预测。候选场景还包括无人机操作响应、设备趋势、数值判断、虚拟宠物、动态难度、有限工具路由、个性化界面、模拟机器人、环境调节、事件回查与异常线索。网页为14个场景逐项写出输入、输出、反馈、基线、风险和最小验证；候选不是已交付产品。

无人机不规则运动：如果只能看到位置，能学反复出现的惯性或操作风格，无法知道飞手下一次临时决定。若有时间戳、姿态、摇杆/控制量与风等已测输入，可研究动作后果模型；更远期预测应给不确定性和误差范围。不同飞手、设备、风况及操作段应隔离评估，本项目没有真实飞行日志、飞控或精度实测。

预测设备温度/位置用随后真实读数教学；选择宠物行为/游戏难度用明确结果奖励；回查事件用线索和真实关联；模拟控制先学动作后果再按目标规划。每个业务要定义哪些输入当时可见，输出何时需要，反馈何时可靠，才能防止偷看未来或把待奖动作配错。

规则清晰可枚举时优先规则；小型状态表先比较Q；短期运动先比较匀速/匀加速度、滤波；明确有监督序列再比较简单回归和序列网络。只有需要研究反馈图、局部教学、状态/记忆或持续适应，而且收益超过求解和维护成本时，Cadence才更值得试。

## 如何用：数据协议、训练、留出验证与部署分工

监督路径：将历史位置与时间变成差分特征 → 用TemporalPatchNet自由预测 → 真后续到达后构造标签 → observe教学 → 在没参与训练的轨迹上检查误差和实际射击。奖励路径：编码公开观察 → Brain.live给动作 → 应用执行 → 将动作对应的真实reward/done交回 → 等待期间用wait，不把未知结果当零奖励。

固定版本、模型尺寸、β、学习率、种子、训练/留出划分及反馈时间，记录输入、输出、状态、参数前后值和执行结果。迁移时保留哪些状态必须写清；保存完整参数、记忆、优化器、随机状态与待奖关系，不能只保存一张权重表就假定续跑一致。

公开网页提供完整研究、原始资料、四店/街区历史回放、真实神经/资格/更新帧以及鱼的预测、实际轨迹和命中记录。按钮播放已完成的Python计算，不能在线新建训练。真实Cadence、手动奖励搬家与新种子训练通过本机Python服务运行，运行命令保留在项目README。

源码、图、JSON与授权一并保留。本地Three.js街景是表现层，NPC没有学习三维路径；捕鱼射击碰撞由应用规则计算。公开版没有外部模型密钥、账号或飞行控制后台，数值端点动画不冒充求解器中间帧。

## 对你的价值：可复用的实验资产和选型判断

学习价值：用同一真实样本把输入、活动、权重、误差、奖励和资格归因分开，看到监督预测与强化学习各自怎样工作。已有数字播放器、两侧相减动画和七步β关系推导可反复核验，无需先相信术语。

开发价值：已获得位置历史编码、预测/拦截评估、NPC反馈顺序、等待处理、可复现种子和数据回放等骨架。你可以替换鱼/街区数据，保留规则和Q等基线，用相同指标检验新算法是否值得增加。Cadence提供研究机制，不替你准备数据、业务反馈和上线验收。

决策价值：现有对照告诉你哪里简单方法已经足够，哪里有可学习结构，以及错误指标如何误导选型。对捕鱼先做可靠的运动基线和独立评估；对游戏NPC先把行为菜单与奖励闭环做对，再研究记忆和适应。没有验证节省工时、付费意愿、商业回报或普遍泛化，不把这些推断成已取得的收益。

## 扩展方向：从新数据验证到记忆与规划组合

第一阶段补评估：增加未见种子、轨迹/飞手/环境隔离，报告短中长期误差、碰撞命中、适应延迟、旧技能保留和运行成本。保留失败样本，冻结开发后的配置再跑独立确认集；现有实验数量不能代替这一步。

第二阶段补输入：引入真实控制量、姿态、时间间隔与工况，逐项消融验证信息是否有用；把未知/缺失观察明确编码。第三阶段补基线与不确定性：同预算比较滤波、线性/非线性回归、GRU/LSTM与合理记忆基线，校准误差区间或多模态后果。

第四阶段研究记忆和持续适应：线索别名、容量、遗忘、旧技能干扰、反馈延迟和保存后续跑分别量化；RecordPatchNet、BeliefPatch与默认Brain组合须写接口和状态边界。第五阶段研究动作后果和有界plan，在模拟器执行测量，防止模型误差被规划放大。

第六阶段完善产品工程：训练任务队列、检查点、可取消/可恢复、数据版本、结果对照和本地/后台协议；如需在线新训练，再独立部署Python计算服务并验证成本与并发。GPU、扩大模型和更长序列都先测求解与行为收益，不从数学能量直接推断省电。
