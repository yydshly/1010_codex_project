# 算法单步可视化

2026-10-11，在街区演示 `http://127.0.0.1:8190/route.html#algorithm` 增加真实计算帧。该页面继续使用固定 Cadence `19bee92756d1842176ad30b1cd01edbfbfa3f14c`、规则记路与 Q-learning；来源及许可证见 [THIRD_PARTY](../THIRD_PARTY.md)。

## 如何观察

1. 点击顶部「算法单步」，从初始观察开始按「下一算法步」。已记录的帧只回看；走到末帧才请求一个新的环境时刻。
2. 观察 8 维公开输入、42 个实际神经活动、动作概率与被抽中的动作。初始种子 7 的东街概率略低于西街，仍被实际抽中，可区分抽样和贪心。
3. 在「待奖资格」帧切换自由态、+β、−β；切换本次对比 C 与累积资格 E。刚发出的动作只保存扰动资格，反馈到达时才合入 E。
4. 两次 wait 都保留 D2 和资格。工作轨迹与神经活动可以变化，图参数、Critic 和联想记忆不变。
5. 第一趟终点命中 +1，TD 误差为 1；查看「累积资格」「参数更新」及「终点清理」。种子 7 的该次更新改变 386 条连接，然后资格清零，继续下一趟。
6. 点击连接热图或输入 0–449 编号，读取这条连接的 C、E、权重前后值与实际 Δw；两个端点在神经活动中用金边标记。「查看峰值连接」恢复随本帧最大值选择。

支持上一帧、时间轴、片段回看和 0.8／1.6／3 秒逐步播放。算法播放与整趟加速观察互斥；改变条件新建实验，迁移继续原参数。规则／Q 的最近结算明确标记环境时刻，避免把前一时刻结果当作当前帧结果。

## 数据来自哪里

新增 [algorithm_trace.py](../runtime/algorithm_trace.py) 在服务器的街区会话上安装实例观察包装器。自由态来自原 `_choose` 的参数；正负扰动态来自 Actor 的真实 `_pending`；资格来自实际 `Learner.apply` 调用前的 Actor 迹；参数差来自同一次应用的前后数组；Critic 和联想矩阵差在真实反馈调用完成后记录。记录器不替代动作、不训练或重新求解神经图。

为在首次 `live` 前安装观察器，服务器初始化时按同一种子和配置重建尚未执行环境行动的 Cadence 控制器；基线保留。初始构造的额外成本不计入离线基准。此后各动作、奖励与等待沿原协议执行，整个会话保留同一被观察的 Brain。

初始观察帧还没有发出动作或形成工作轨迹；选择帧才出现 D1。等待输入帧携带当时的实际 drive，活动帧读取真实等待求解结果。奖励始终归属旧动作；下一趟输入与动作另占后续帧。

为控制会话和响应大小，只保存最近 **96 个算法帧**。本次记录导出包含这些帧及完整环境行动，但不提供所有过去的内部帧。可播放的是自由态、扰动态与实际更新边界，不逐个重演求解器内部的数值迭代。颜色按组／指标的本帧峰值缩放，数字保留真实值；颜色强弱不能跨组或跨指标直接比较。

实时控制器计时包含记录开销，不用于新的速度排名。原 24 次离线实验、协议源文件与成绩保持不变，生产构建仍校验原评估的三个源文件 SHA256。加入观察器不视为新性能基准。

## 已运行的验证

- 全部 **33 项 Python/API 测试通过**，包括新增 6 项记录器检查；API 返回算法帧及真实 450 维参数数据。
- 四种条件的带记录与原实验逐步对照：12 趟、三个短阶段的行动历史、图效力／偏置、Critic、活动轨迹、快慢联想记忆、随机状态和唤醒状态完全相等。
- 检查实际资格符合 `E=0.72·旧E+C`，终点之前读取其参与更新的值，之后清零；权重差等于实际前后参数之差。
- 检查平静动作不生成 Actor 更新或采样资格；等待保留旧动作；立即重试 API 不重复发帧或结算。
- 浏览器帧、正负扰动态、回看不推进环境及实际参数更新的核对见 [浏览器凭据](algorithm-browser-verification.json)；原始可见帧见 [algorithm-browser-frames.json](algorithm-browser-frames.json)。
- 本次更新前已完成的 360 趟会话保存为 [原会话备份](pre-algorithm-completed-session.json)，Cadence 找到 257 趟。新界面从新的种子 7 会话开始。

生产构建通过。浏览器逐帧读取种子 7 首趟的 28 个可见帧，全部向量和标量与同条件 Python 真值完全一致；正负扰动态切换、自动播放、时间轴首尾和回看不推进环境均已验证。1280×960 为双栏，390×844 为单栏，页面均无横向溢出；验证后恢复默认视口。实际截图见 [更新全过程](../assets/algorithm-update.png) 和 [手机布局](../assets/algorithm-mobile.png)。
