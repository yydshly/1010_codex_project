# 子项目目录

这里存放真实的研究子项目。对外索引位于 [根 README](../README.md)，登记表位于 [projects.json](../projects.json)。

目录从 `001-slug` 起编号，按编号升序展示。使用根目录的创建命令生成模板，不把模板当作正式研究条目。

每个项目使用以下结构：

```text
001-slug/
├── README.md       # 项目介绍、上游版本、复现与结论
├── notes/          # 研究过程、架构分析、实验记录
├── assets/         # 截图与说明图片
└── web/            # 可选 Web 应用，自行管理依赖
```

实验代码可按需要增加 `experiments/` 等目录；大型上游仓库下载到本地被忽略的 `vendor/`，或只在笔记中记录地址与固定版本。
