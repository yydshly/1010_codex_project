# 003 · 霓虹裂隙 · AI 指挥官机甲战

NEON RIFT 是一个本机可玩的原创 3D 机甲动作原型：驾驶裂隙先锋，在霓虹工业平台上移动、射击、冲刺与释放脉冲，突破三波封锁，击破最终重装守卫。

这次根据实际试玩反馈，把原来的雾港策略画面改为动作战场。项目编号仍为 003，目录 `003-fog-harbor` 保持固定；旧游戏及实测记录保留在 [旧版入口](http://127.0.0.1:5193/legacy/harbor/) 和 [历史说明](notes/harbor-v1/README.md)。

## 直接体验

本机入口：[霓虹裂隙](http://127.0.0.1:5193/)。需要本机服务运行；尚未公网部署。

![霓虹裂隙实际 3D 机甲场景](assets/neon-rift-desktop.png)

想自己驾驶并观察战术变化，点「你来驾驶 · OpenAI 动态指挥」。首波部署后停在简报，点击开战再开始采样。想先看动作效果，点「动作演示」：普通电脑自动驾驶，连续展示三波进攻、推进残影、弹道、命中粒子、范围脉冲与重装守卫，不调用模型。选择指挥官并点击「开始出击」可体验原有的每波部署模式。

点「OpenAI 战术观战」可直接让平台 OpenAI 指挥敌人，我方使用规则自动驾驶。每波命令返回后先展示输入和公开理由，点「执行命令」交战；左侧实时对照普通电脑的固定战术。粉色线显示实际敌方导航目标，灰色虚线是相同位置、相同时间使用普通电脑战术得到的目标，不是另一局战斗的轨迹。默认 0.45 倍速同时放慢双方，可切回 1 倍速。战术记录导出包含实际模型输出、每波结算和导航采样。

- WASD / 方向键移动，鼠标瞄准；动态模式按住鼠标左键 / 空格射击，常规模式自动射击。鼠标离开战场时自动瞄准最近敌人。
- Shift 移动中冲刺，短暂无敌；Q 释放范围伤害并清除附近敌方弹幕。
- 反应堆提供掩护；青色晶体恢复生命与护盾。波次之间休整。
- 可以开关合成音效、辉光，暂停、查看战术记录和导出本局 JSON。

## AI 实际做什么

敌方指挥官支持 MiniMax、平台已有 OpenAI 登录和普通电脑。常规模式在**每波开始之前**读取位置、生命、护盾、射击命中与技能次数，选择阵型、进攻侧和推进节奏，并返回公开的战术命令、简短理由和无线电台词。有效命令会改变敌人的实际移动目标与推进速度。

普通电脑按波次固定选择「突击 → 围攻 → 包夹」，不会根据你的打法调整。在同一玩法模式内，指挥官使用相同的敌机数值、并发数量、伤害、射击节奏与技能规则；模型只能选择预定义战术，不能增加伤害或改写胜负。当前实现的是可观察的指挥层 AI，并未训练逐帧控制或强化学习模型，也不能凭一次对局判断它更强。

常规模式每局最多发起 3 次模型请求，等待期间战斗暂停；接口错误会明确显示，允许重试或由玩家选择本波规则替代，不把替代结果写成模型决策。页面加载、选模型和普通电脑演示均不请求模型。

新增「你来驾驶 · OpenAI 动态指挥」：手动移动，按住鼠标或空格射击，Shift 冲刺，Q 脉冲。每波有 45 秒援军窗口，结束后清除剩余敌人进入下一波；援军使用相同敌机数值，只生成新单位。模型读取最近约 12 秒的位置采样、射击命中及技能增量，首次在战斗 3 秒后评估，后续请求至少间隔 8 秒。模型生成需要时间，战斗持续执行上一条命令；新命令返回后只修改存活敌人的导航目标和速度。

动态模式每局最多 18 次模型请求（包括部署、失败和取消），前端每波最多 4 次战斗中调整，并预留后续波次部署额度。暂停期间的返回命令等到继续后再校验，超过 30 秒或跨波次的命令忽略。战术记录区分「已执行」「保持相同战术」「待执行」「忽略」「失败」，导出同时保留模型生成记录与客户端应用结果。它是有延迟的战术指挥，不是逐帧遥控。浏览器已实测“西侧包夹 → 东侧围攻 → 西侧包夹”两次战斗中调整，实际改变存活敌机的导航目标，见 [动态实测记录](notes/openai-dynamic-browser-2026-10-11.json)；此轮验证完成第 1 波，未声称三波手动通关。

## 运行

```powershell
cd F:\codex_project\1010_codex_project\projects\003-fog-harbor\web
npm.cmd ci
npm.cmd start
# 另开终端：
npm.cmd test
npm.cmd run check:api
npm.cmd run build
```

前端为原生 HTML/CSS/ES Modules，Three.js 0.180.0 在子项目内管理，通过本机服务加载；后端 Node.js 22+。MiniMax 使用用户指定的外部配置 `F:\codex_project\.env.minimax`；OpenAI 使用官方 Codex CLI 管理的现有登录，不提取凭据。见 [配置与构建说明](web/README.md)。

## 价值与下一步

这版把视觉风格和 AI 的价值放进可操作的场景：机甲动作负责即时反馈，模型根据实际操作记录调整战术，本地执行器在等待期间持续战斗。可以复用「状态 → 模型命令 → 白名单校验 → 本地执行 → 结果反馈」这条链路，继续扩展角色行为树、可破坏场景、任务导演、机甲装备或多局对照评测。当前是三波单场原型，尚未完成关卡编辑、长期记忆、联网对战或商业效果验证。
