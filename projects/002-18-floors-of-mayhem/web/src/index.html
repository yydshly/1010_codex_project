03 / WHAT WE CAN BUILD NEXT
把一个游戏，
变成更多可能。
最值得带走的是任务、事件与决策循环。
下面是可以继续实现的方向。

        

          
01
优先尝试 / 与樱花小街结合
让街景拥有可以完成的任务。
探索三个地点、收集资料、获得称号，把“看场景”变成“参与场景”。
查看最小方案 ＋
复用任务状态、事件记录和奖励机制；沿用小镇的三渲二画面。先完成真实操作触发进度、重复操作不重复奖励、刷新后恢复这三个条件。
↳

          
02
继续扩展 / 多人体验
让朋友一起进入同一个世界。
共享收集进度、分工探索或互相帮助，用房间连接一段共同经历。
查看最小方案 ＋
先同步任务事件，再增加角色移动。借鉴房间、权限和重连机制；小镇的坐标与交互需要另行实现。验证两台真实设备的状态一致。
↔

          
03
研究方向 / Agent 实验
让 NPC 不只是说话，也能行动。
模型选择地点与任务，本地执行器完成移动和交互，用结果评价策略。
查看最小方案 ＋
把平台观察替换为地点与任务资源。相同初始条件下，对照规则、模型无记忆、模型带记忆；记录完成率、耗时与调用量。
↗
